# 完成后是否切回起始账号

在“一条龙运行 → 运行设置”中，可以设置“完成后切回起始账号”。它用于减少全部账户完成后不必要的切号、登录和等待。

- 开启：保持原行为。全部参与账户完成后，仍执行返回起始账户的切换流程。
- 关闭：最后一个参与账户完成后直接结束，游戏账号和当前账户配置都停留在最后一个账户。

例如参与账户为 1、4，从账户 1 开始：开启时是“1 执行 → 4 执行 → 切回 1 → 结束”；关闭时是“1 执行 → 4 执行 → 结束”。

开关默认开启，已有配置不需要补填。想减少最后一次切号时，关闭该开关即可。它对本次参与轮换的账户整体生效；单账号或“仅运行当前”仍只执行一次。

从列表中间账户开始时，仍会把每个参与账户执行一遍。例如参与账户为 1、4、7，从 4 开始且关闭开关，会按“4 → 7 → 1 → 结束”执行。

“结束后”的设置独立生效：如果选择关闭游戏，仍会关闭最后运行的游戏；如果选择关机、休眠或睡眠，仍会执行对应动作。“停留在最后一个账户”不表示取消这些结束后动作。

账户之间使用各自原有的登录配置，账号密码和历史账号登录方式均可沿用。不同游戏路径的正常中途切换不变，关闭开关只省去全部完成后的返回切换。
