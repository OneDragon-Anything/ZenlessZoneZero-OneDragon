# 咖啡应用运行方案

## 概述

`CoffeeApp` 负责每日咖啡的选择、点单、可选喝后挑战，以及咖啡流程结束后的后续处理

咖啡应用只负责咖啡业务的判断和编排。普通体力计划仍由 `ChargePlanApp` 管理；咖啡结束后的兜底计划由咖啡应用生成，再通过体力计划应用提供的一次性执行入口运行

## 咖啡选择

- `优先体力计划`：按计划列表顺序匹配本轮尚未完成的计划和对应预设增益咖啡；没有匹配时选择汀曼特调
- `汀曼特调`：固定选择汀曼特调

选择咖啡前会先按体力计划的每日重置设置同步运行次数，避免跨刷新日沿用上一日的完成状态

匹配时会跳过无增益咖啡和不符合当前副本类型、任务类型或具体任务的咖啡。旧配置中的浓缩咖啡会迁移为汀曼特调，咖啡候选中不再提供浓缩咖啡选项

## 喝后挑战

喝后挑战发生在点单后的“选择前往”分支，会直接调用对应副本操作，不会调用 `ChargePlanApp`，也不会计入普通体力计划次数

- `全都挑战`：无论对应副本是否已配置在体力计划中，都直接挑战一次
- `只挑战体力计划`：仅用“对应副本是否已配置在体力计划中”判断是否挑战，不会执行该体力计划
- `不挑战`：确认后返回大世界

喝后挑战使用咖啡配置中的预备编队。选择“游戏内配队”时沿用当前队伍，并使用咖啡配置中的自动战斗；选择其他预备编队时使用该编队绑定的自动战斗配置

对应副本已配置在体力计划中时，喝后挑战沿用该计划的卡片数量；找不到对应计划配置时，使用“体力计划外的数量”。配置为默认数量时保持游戏内当前选择的数量，配置为 `1` 时将卡片数量设置为一张

## 结束后处理

喝后挑战或确认不挑战后，咖啡流程会先返回大世界，再根据 `结束后处理` 执行以下分支

- `不运行体力计划`：结束咖啡应用
- `运行体力计划`：调用 `ChargePlanApp` 执行普通体力计划
- `运行体力计划并兜底剩余电量`：先执行普通体力计划，再按结束时识别到的当前电量决定是否执行兜底计划

兜底计划只在当前电量为 20～59 时生成：20～39 电量生成 1 张卡片，40～59 电量生成 2 张卡片；0～19 和 60 及以上不生成计划

兜底计划由咖啡应用从设置的实战模拟室卡片复制生成，使用独立的计划标识、运行次数和计划次数，不写入普通体力计划列表，也不会修改普通计划的已运行次数。一次性执行结束后，体力计划应用会清理临时运行状态

## 配置迁移

`CoffeeConfig` 初始化时处理旧字段

- 旧 `choose_way=浓缩咖啡` 迁移为 `汀曼特调`
- 旧 `run_charge_plan_afterwards=true/false` 迁移为对应的 `结束后处理` 三态中的运行体力计划或不运行体力计划

迁移完成后保存配置，后续运行只读取新的字段
