# 首次启动恢复

恢复只在本任务第一次入场前执行。失败结算仅识别 DEFEAT，不核对地图名称；退出确认须识别仅保留安全箱的专用提示。未知画面或仓库出售中状态停止。

正在进行的局内识别普通攻击按钮和计时后，复用正常退出流程，不打开大地图查询，也不核对地图名称。已打开的大地图通过图例识别，先关闭再识别局内画面。明确的贝果搜查面板先关闭，再识别局内画面。正常退出仍须识别仅保留安全箱的专用提示。

退出遗留局会丢弃安全箱外的物资，不续原路线。退出操作完成后重新截图，再处理启动仓库，不能拿旧结算帧继续判断入口。

启动转存同时核对背包、安全箱和仓库容量；不增加成功次数、出售间隔或失败重试。普通转存不主动出售，满仓或残留按[一次出售再入仓](bagel_sale_interval.md)处理，使用应用实际清理开关和筛选。关闭清理、未知容量、再入仓后仍残留或最终仓满均停止。

保留原入场的清空装备、零携带、零投资与首次资格保护。暂停不重新获得启动恢复资格。

离线覆盖真实节点图与存档截图。2026-10-10 联合实机验收从自动准备的贝果局内启动，正常退出至DEFEAT，再进入仓库并返回入口，随后完成3个成功局。准备入场不计成功；恢复时背包和安全箱均空，没有出售，首个成功局的出售计划仍从0/2开始。

本轮只验证局内起点和空遗留物资恢复；非空遗留转存、已有失败页或退出框起点、搜查面板和大地图起点未实机覆盖，不把空箱恢复推广为所有恢复分支通过。
