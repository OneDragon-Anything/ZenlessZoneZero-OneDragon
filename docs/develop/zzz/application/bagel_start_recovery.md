# 首次启动恢复

恢复只在本任务第一次入场前执行。

- 失败结算识别 DEFEAT，不核对地图名称。
- 退出确认必须包含仅保留安全箱的专用提示。
- 仓库处于出售状态时停止。未知页面仅允许既有[页面阻挡恢复](bagel_failure_retry.md#页面阻挡恢复)，仍无法识别时停止。

正在进行的局内识别普通攻击按钮和计时后，复用正常退出流程，不打开大地图查询，也不核对地图名称。已打开的大地图通过图例识别，先关闭再识别局内画面。明确的贝果搜查面板先关闭，再识别局内画面。正常退出仍须识别仅保留安全箱的专用提示。

退出遗留局会丢弃安全箱外的物资，不续原路线。退出操作完成后重新截图，再处理启动仓库，不能拿旧结算帧继续判断入口。

启动转存同时核对背包、安全箱和仓库容量；不增加成功次数、出售间隔或失败重试。普通转存不主动出售，满仓或残留按[一次出售再入仓](bagel_sale_interval.md)处理，使用应用实际清理开关和筛选。携带物已清空且容量可读时，满仓也允许继续；有残留但清理关闭、未知容量或再入仓后仍残留则停止。

保留原入场的清空装备、零携带、零投资与首次资格保护。暂停不重新获得启动恢复资格。

离线测试使用真实节点图与归档截图，覆盖范围见测试仓[覆盖说明](../../../../zzz-od-test/BAGEL_COVERAGE.md)。离线画面切换不能证明游戏接受了输入。

非空遗留转存、已有失败页或退出框起点、搜查面板和大地图起点尚未完成实机验证。局内起点和空遗留物资恢复缺少已归档的连续验收证据，不能据此认定所有恢复分支已通过。
