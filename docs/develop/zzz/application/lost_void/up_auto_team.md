# 迷失之地 当期UP自动配队

> 特遣调查 / 矩阵行动 识别当期UP代理人后,从角色池自动选出「UP+搭档」的配队出战。
> 代码:`operation/lost_void_up_team.py` + `lost_void_app.py` 的 检查预备编队 / matrix_* 节点。

## 为什么

- 特遣调查:任意一位当期UP通关可获每周特遣补给;矩阵行动:当期UP有玩法加成。
- 原「当期UP代理人」开关只做「与预备编队比对选UP最多的编队」:预备编队没配 / 没包含UP时
  静默回退固定编队,拿不到UP收益;新UP角色往往不在既有编队里,自动配队补上这块。

## 配队规则(compute_up_lineup)

1. 已拥有的UP全部进队。拥有判定 = 出现在任意预备编队里(「预备编队」页配置或识别)。
2. 一个UP都没拥有时,用第一个UP保底 —— 特遣调查出战画面的选人面板含**试用**代理人,
   未拥有的UP也能用试用版上场拿补给。
3. 剩余空位按「与已选UP同队次数 → 总出场次数」从高到低补搭档(排除未拥有的UP,
   试用角色没有玩家装备,不适合当搭档)。

## 特遣调查流程

`检查预备编队` 节点内(开关 `up_team_auto_compose`,需与 `choose_team_by_priority` 同开):

1. UP列表来自入口画面识别(官方已有,`priority_agent_list`)。
2. `LostVoidComposeUpTeam`:OCR三个槽位名字得当前编队 → 算出需要换的槽位 →
   逐槽点开选人面板 → 头像模板匹配找目标(翻页,页内容不变时换拖拽起点)→
   点卡片 + 点右侧丝带确认。
3. 校验:再OCR槽位名字,含≥1个UP即成功;失败回退原预备编队匹配路径。

画面机制要点(实拍归档 `screens/通用-出战/`):

- 槽位中心 x≈475/950/1430 y≈540;名字OCR区见 `NAME_RECTS`。
- 选人面板斜排卡片,**排序随槽位/替换模式变化**,目标可能在任意页。
- 右侧丝带:占用槽替换模式=CANCEL,**空槽模式=SELECT(会把默认高亮卡确认进队)**
  → 放弃选择必须点左上返回箭头,不能点丝带。

## 矩阵行动流程

三个节点(开关 `matrix_up_auto_team`):

1. `矩阵行动-前往入口`:先停在矩阵入口面板,识别右下「UP代理人」头像行
   (`recognize_matrix_up`,协战头像带「协战」标签、固定最右,识别不到标签按最右兜底);
   再点下一步进编队选择。
2. `矩阵行动-点击预备编队`:编队选择网格再做一次UP徽章识别(`find_up_in_agent_grid`,
   徽章OCR召回约一半,与入口识别取并集)→ 算配队 → 走官方「手动选取角色」机制选人。
3. 协战代理人:官方逻辑本就UP优先(找不到UP点第一个,UP固定在协战池首位),不改。

画面机制要点(实拍归档 `screens/迷失之地-矩阵行动*/`):

- 入口「UP代理人」头像行 Rect(1480,680,1850,810);UP徽章在卡片左上,与卡片中心偏移
  |dx|≤95 |dy|≤110 内关联。
- **矩阵面板「下一步」与编队选择「开始挑战」按钮坐标重叠**(1633-1811,998-1052):
  过场中重复点击会误点开始挑战,空编队时弹「至少选择1位代理人出战」模态
  (无画面档案,会卡死识别)→ 下一步只点一次后等待,弹窗出现时点确认交由选人流程填队。
- 编队选择过场加载可超30秒 → 未识别画面只等待不点击(防路由盲点坐标)。

## 相关修复(同PR)

- `check_predefined_team`:预备编队匹配失败(没配编队/编队里没UP)时不再把
  `use_priority_agent` 置 True —— 原逻辑会在通关后误标记「本周已用UP完成」,
  本周内配好编队也不再尝试;现在匹配过程与失败原因写日志。
- `ChoosePredefinedTeam.choose_team`:编队名匹配收紧(`match_team_name`)。
  原 `difflib.get_close_matches`(cutoff 0.6)会把不在当前页的「编队8」按 0.67
  相似度匹配到「编队1」→ 点错编队且永远不触发翻页;现在同前缀不同编号不允许
  模糊命中,找不到才走翻页。影响所有使用预备编队选择的入口,不限迷失之地。
