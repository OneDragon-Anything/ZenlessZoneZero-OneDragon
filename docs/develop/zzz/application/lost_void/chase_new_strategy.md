# 调查战略追新选择

挑战配置开启「追新模式」（`chase_new_mode`）时，进入战线肃清 / 特遣调查前在调查战略列表里选还没刷满的战略。代码在 `LostVoidApp._choose_strategy_by_chase_new_mode`。

## 流程

1. 打开调查战略列表时重置扫描状态（节点「打开调查战略列表」），按钮区域取当前副本自己的画面（`迷失之地-{副本名}`）。
2. 先向左拖到列表开头，再向右逐页检查，一直拖到最右边、看完整个列表后才选。每次拖动约 1500 像素（原来 800 像素一次只移动 3 个战略）。
3. 是否到头：用已识别战略的名称和横坐标判断，连续两页名称相同、位置相差不超过 5 像素就算到头，不按固定拖动次数结束。
4. 看完后选已确认等级最低的战略，同等级按战略列表顺序选第一个；选中后按名称拖回去点击（`_choose_strategy_by_ocr(strategy_name)`）。
5. 没有任何可确认的候选时，沿用原来的回退：点击当前页第一个等级圈圈。挑战配置开启 `stop_when_no_strategy` 时改为返回大世界并结束本次运行（见 [无脑挂机刷菲林](afk_polychrome.md)）。

## 等级识别

- 等级圈圈（流水线「调查战略等级圈圈」「调查战略无等级圈圈」）只用于定位，圆度低于 0.7 的轮廓忽略；圈圈左侧最近的战略名称就是它所属的战略。
- 白色数字从圆圈内部提取（`_recognize_strategy_level`）：
  - 有两个封闭孔的是 8，按满级排除；
  - 其余数字用单字 OCR，只有明确读出的 0～7 才参与选择，读不出的跳过并记日志。
- 黑色空圆圈：必须同时通过「无等级圈圈」检测且内部没有白色数字，才算 0 级（未收集），最先被选中。

## 为什么改

原来的写法看到第一个「没识别到数字」的圈圈就点：数字识别失败时满级战略会被当成未满级选中；最多只往右拖 3 次，列表打开时如果停在中间，左边的战略永远看不到。
