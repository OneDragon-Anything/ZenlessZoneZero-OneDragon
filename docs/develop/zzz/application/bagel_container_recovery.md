# 贝果容器停稳确认与开箱恢复

本说明适用于武备箱和电子保险箱。导航负责停稳确认与短步重新靠近；开箱操作负责发送交互输入与确认面板；流程执行器管理共享预算。玩法和识别区域见[贝果画面](../../../game/screens/贝果计划.md)。发布流程的目标坐标保持不变。

## 容器阶段与预算

一个容器阶段由流程中的靠近步骤及其后紧接的交互步骤组成。执行器用靠近步骤的 ID 区分阶段。例如，流程包含两个武备箱时，两组靠近步骤使用不同 ID，各自拥有独立预算。只勾选交互时，该交互仍归属其对应阶段，但不能调用未勾选的靠近步骤。

执行器先确定当前阶段，再检查该阶段的预算。切换到另一阶段时建立新预算；同一阶段切换子操作、补按或重新靠近时保留原预算。

| 限制 | 计入范围 | 上限 |
| --- | --- | --- |
| 有效运行时间 | 首次识别目标提示或进入目标交互距离后，累计靠近确认和开箱耗时；扣除人工暂停时间 | 30 秒 |
| 重新靠近次数 | 首次靠近后的额外恢复，不按短步输入次数计数 | 2 次 |
| 开箱 F 次数 | 首次开箱和所有补按；发送前占用次数，发送后报错不返还 | 3 次 |

长距离导航沿用原导航时限。电子保险箱的光圈点按属于后续解锁阶段，不占开箱 F 次数。任何恢复输入前都要检查预算；预算耗尽时松键并返回失败。

## 靠近与停稳确认

1. 导航首次识别目标交互提示和 F 图标后，松开前进键。
2. 等待 0.5 秒，再读取松键后的新截图。动作前的截图不能完成到达判断。
3. 核对局内 HUD、当前可靠位置、目标交互提示和 F 图标。当前位置必须处于目标的交互采信距离内，才报告靠近完成。
4. 停稳后提示消失时，先核对当前可靠位置，再申请重新靠近。恢复只使用短步，不恢复持续前进；提示再次出现后重复停稳确认。

位置与目标提示冲突时立即失败。定位证据暂缺时先松键，按既有定位规则有限等待，不用历史坐标继续移动。定位恢复后才允许短步。

恢复的到点范围取原到点半径与 0.5 像素中的较小值，避免角色仍处于普通到点范围内时只空等。达到该范围后停止移动并等待提示；等待 2 秒仍无提示则失败。

## 开箱观察与恢复

F 输入后先观察 2 秒，再按当前截图处理：

| 当前画面 | 开箱操作与执行器的处理 |
| --- | --- |
| 正确搜查面板或电子保险箱解锁界面 | 完成开箱，交给对应后续步骤；不再移动或发送开箱 F |
| 面板特征不完整或画面不明 | 松键并继续观察，不发送开箱输入；仍受阶段时限约束 |
| 局内 HUD、目标提示和 F 图标均存在 | 预算允许时补按 F |
| 局内 HUD 存在，目标提示或 F 图标消失 | 持续消失 0.5 秒后申请重新靠近 |
| 已确认整局失败结算 | 返回既有撤离失败状态 |

任何容器面板特征出现后，都禁止恢复移动与重复开箱。另一类容器的面板不能作为当前目标的成功结果。

## 正式应用与分步执行

只选靠近时，可以在该步骤内重新靠近并确认停稳，不能隐式开箱。只有当前阶段的靠近步骤已被选中并成功完成，交互步骤才能调用它恢复。只选交互时允许补按；提示消失则返回失败，不能补做未选移动。已有正确面板时，靠近和交互直接完成。

恢复失败返回独立业务失败状态，并携带定位、交互或预算耗尽原因。操作基类保存失败截图。正式应用进入既有失败局退出与仓库结算流程；开发工具返回失败并保留现场，不自行开新局。局部恢复成功不增加整体失败次数。

## 参数依据与验证范围

停稳等待沿用已有保险箱提前松键参数。F 后观察间隔沿用武备箱补按间隔。提示消失等待用于区分短暂识别缺失与持续丢失。恢复到点范围限制用于避免原到点范围阻止短步恢复。

离线测试使用真实存档、OCR、画面区域及完整节点执行。控制器按输入推进画面；受控时钟覆盖等待、暂停和预算边界。子操作使用独立看门狗，业务时限失效时测试也能有限结束。

测试位于独立仓 `zzz-od-test`：执行器行为见[恢复测试](../../../../zzz-od-test/test/zzz_od/application/bagel/bagel_run_flow/test_container_recovery.py)和[阶段边界测试](../../../../zzz-od-test/test/zzz_od/application/bagel/bagel_run_flow/test_container_boundaries.py)，正式应用的失败路由见[应用测试](../../../../zzz-od-test/test/zzz_od/application/bagel/bagel_app/test_run_flow.py)。位移与跨阶段场景包含受控合成数据，用于验证执行逻辑。

不同角色的实际停步位移，以及这些参数对不同角色的适用范围尚未完成连续实机验证。离线回归不能替代实机验收。
