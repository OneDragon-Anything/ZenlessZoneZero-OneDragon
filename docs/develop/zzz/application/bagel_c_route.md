# C 路线：单廊双容器

路线文件为 [六昏街南站-默认.sample.route.json](../../../../config/bagel/routes/六昏街南站-默认.sample.route.json)，绑定出生点「六昏街南站」，属于 `雅努斯幻境/Custom`。它保留旧 C 路线的顺序：从长廊出生点出发，搜查机械保险箱，沿西侧道路绕至电子保险箱。

该路线使用当前打点执行器。开箱、收集和关闭面板按点类型执行，正常退出由正式应用负责，见[贝果自动化说明](bagel.md)。不恢复旧地图定位器或 `flow.yml` 执行链。

电子保险箱与[录像店路线](../../../../config/bagel/routes/录像店-默认.sample.route.json)使用同一目标坐标 `(947,358)`。旧底图换算得到的 `(940,357)` 过早进入当前执行器的原地等待半径，角色可能尚未触发交互提示就跳过。统一目标点使执行器继续接近，实际开箱仍以现场提示为准，不要求走到箱子坐标。

## 坐标转换依据

旧 C 路线使用以参考出生画面为基准的相对坐标，当前路线使用分层底图的全局坐标。前九点按下式转换，电子箱目标按上节与既有路线统一。转换先读取旧底图的 `origin_xy=(-165,-140)`，得到旧底图像素位置 `(u,v)=(旧x+165,旧y+140)`，再映射到当前 `Custom` 层，最后取整：

```text
新x = 0.9982797077 × u - 0.0107407598 × v + 741.0870854
新y = 0.0107407598 × u + 0.9982797077 × v + 224.4223300
```

矩阵由两份底图的局部图像特征匹配和一致性筛选得到，保留 42 对匹配点，映射误差中位数约 1.02 像素。该值描述底图之间的几何对应，不是实机定位误差或路线通过率。
