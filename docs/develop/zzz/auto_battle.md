# 自动战斗补充说明

## 队伍角色识别兜底

自动战斗中的队伍角色识别，原本会在连续多次识别结果一致后，停止全量匹配，转为基于当前队伍信息的低成本识别。

当游戏内出现同一队伍在战斗中循环切换的新模式时，旧的低成本识别可能会因为候选角色被固定，导致当前画面一个角色都识别不到。

针对这个场景，当前实现增加了一个兜底策略：

- 当普通攻击按钮可用，说明当前仍处于战斗画面。
- 如果这一帧角色识别结果为“一个角色都识别不到”，则不立即常驻开启全量识别。
- 仅将下一次角色识别强制切回“全量匹配所有角色”，并重置识别节流时间。

这样可以在兼容新模式的同时，尽量减少常规战斗中的模板匹配压力。

## 战斗按钮提示

战斗画面中的部分按钮会通过模板匹配写入状态，供自动战斗状态判断与调试提示使用。

- 普通攻击按钮用于快速判断当前是否仍处于战斗画面。
- 切换后援按钮每 1 秒检测一次，识别命中时会写入状态 `按键可用-切换后援`。
- 自动战斗可直接执行原子操作 `按键-切换后援`，默认键盘键位为 `R`。

### 按键禁用状态

部分玩法会禁用普通攻击、特殊攻击、终结技，此时按钮仍在原位，但显示的是禁用图标。识别不到按钮可用时，再对三个位置做一次禁用图标模板匹配，命中则写入状态 `按键禁用-普通攻击` / `按键禁用-特殊攻击` / `按键禁用-终结技`。

- **禁用和可用不是互斥关系**：按钮外圈的进度环和中心的 X 图标是两个独立的画面元素，禁用期间外圈可以照常显示，所以 `按键禁用-X` 和 `按键可用-X` 会同时成立。写条件时不要假设互斥，也不要拿「没识别到禁用」反推「可用」。游戏机制见 [按键禁用](../../game/mechanics/按键禁用.md)。
- 禁用期间只在首次命中的那一帧记录触发时间，之后不刷新，所以可以用带时间下限的条件判断已经禁用了多久，例如 `[按键禁用-特殊攻击, 3, 999]` 表示禁用已持续 3 秒以上。
- 普通攻击按钮的可用图标和禁用图标任意一个命中，都算仍在战斗画面，避免按钮被禁用时误判为战斗结束。
- 三个禁用图标只在对应按钮识别不到可用时才会去匹配，不增加常规战斗的开销。因此 `按键禁用-*` 的判定依赖「识别不到可用」这个前提；判定逻辑里没被检测到的禁用状态按未禁用处理（会清掉已有记录），这是为了让禁用解除后能及时复位。

### 首领交互

部分首领会在战斗中途禁用终结技，期间需要按空格切人而不是放终结技。这套交互由两半组成：

**1. 认出是哪个首领**

检测任务 `boss_avatar`（`src/zzz_od/game_data/target_state.py`）每 10 秒跑一次，不经过 CV 流水线，直接裁剪「战斗画面」的 `首领头像` 区域（右上角，1711,52 - 1837,99），逐个模板匹配，命中第一个就停。上一次命中的首领下一轮优先试，靠 `TargetStateChecker._preferred_state` 记住。

新增一个首领只需要做两件事：在 `assets/template/target_state/` 下建头像模板（多边形遮罩避开左侧血条和左下角数值），在任务的 `state_definitions` 里追加一条 `TEMPLATE_MATCH_MULTI` 状态。不要为每个首领各建流水线或各建一个检测任务。

**2. 按首领动作**

具体动作写在 `config/auto_battle_state_handler/首领交互.sample.yml`，`states` 用 `[首领-XXX, 0, 999]` 分流。以薇斯珀为例：

```yaml
- states: "[首领-薇斯珀, 0, 999]"
  interrupt_states: "![按键禁用-终结技, 0, 999]"
  debug_name: "薇斯珀-首领交互"
  operations:
    - op_name: "等待秒数"
      seconds: 2.646
    - op_name: "按键-切换角色-下一个"   # 空格默认绑这个动作
    ...
    - op_name: "等待秒数"
      seconds: 10
```

- 触发挂在「自动守护」和「全配队通用」的 scene 上，`triggers: [按键禁用-终结技]`，`priority: 100`。
- 每段间隔用「等待秒数」而不是 `pre_delay`：等待可被 `interrupt_states` 打断，`pre_delay` 内部是 `time.sleep`，打断不了。
- `![按键禁用-终结技, 0, 999]` 的意思是「终结技仍在禁用」，所以禁用一解除就中断整套动作。
- 时间轴来自实机录制，见 [按键禁用](../../game/mechanics/按键禁用.md) 的实测记录。
