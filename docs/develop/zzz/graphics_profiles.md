# 可选画质配置库

手动玩游戏与自动任务可选不同画质，同时保留玩家其他设置。此草稿只提取文件读写库，尚未接入一条龙启动、退出和设置界面，不改变现有运行行为。

## 配置保护

- 调用方显式传入游戏配置路径，只合并已核实的图像字段。
- 保留未知字段、键位、音频、分辨率和原有文本结构。
- 使用文件锁、备份、写前重查及写后读回；不覆盖另一个程序的保存。
- 参考配置默认不启用，需复核游戏版本与硬件后使用。

## 文件编解码

Sleepy 来自 SpectrumQT/XXMI-Launcher，仅处理原生配置文件，保留 GPL-3.0 许可证与来源说明。不包含注入器、mod 运行时、模型或二进制。
