# 库存保持计算核心

先查材料缺口，再按列表顺序补缺。此草稿只提供计算和单场事务逻辑，不注册 Application、不改体力计划，也不启动游戏。

## 计算与安全边界

- 同系列品质按比例折算，经验材料按经验值折算；同一份库存只抵扣一次。
- 库存必须来自本轮完整的新证据，未知、重复或过期数量不能授权刷取。
- 调用方负责库存读取、自然电量、原生单场任务和待核实记录的持久化。
- 每场后重查库存及电量，未核实的消耗阻止继续；不恢复电量、不自动合成、不改周本记录。

## 草稿范围

本次不提供完整设置界面、仓库导航或副本操作。先独立审查计算核心，后续再接独立应用。测试放配套测试仓的同名分支，不放主仓。
