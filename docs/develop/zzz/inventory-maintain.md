# 库存保持与仓库检查

设置材料目标后先读取库存，再按列表顺序调用原生副本。每完成一场重新读取，全部达标或自然电量不足就结束；不购买、不补电量，不改原有刷本计划。

## 用户入口

在独立运行列表中选择「库存保持」，打开设置：新增材料、填写目标、拖动排序并保存。列表显示材料名称和上次数量/目标数量，选中条目查看副本与消耗。运行中或账号切换后不能保存旧窗口里的修改。

「仓库检查」为只读任务。两者均不自动插入默认日常组；运行前需要已进入游戏。

## 实现与边界

- 97 项可补刷目标，涵盖基础养成、晋升、技能、音擎改装、核心技及恶名狩猎材料。不纳入驱动盘；仓库只读项目不伪装成补刷选项。
- 同系列品质按规则换算；经验材料按经验值折算，不自动合成。
- 使用当前助手截图/OCR，核对名称和精确持有数，连续两帧确认。未知不是零，缩略余额不能授权刷取。
- 副本通过原生 CompendiumService、TransportByCompendium、CombatSimulation、ExpertChallenge、NotoriousHunt 生成和执行，不依赖个人列表位置。
- 每次只创建一场临时计划，不保存或重置原有 ChargePlan。恶名狩猎的付费补刷不消耗/改写原生免费周次记录；免费次数仍有剩余时不会混用该入口。
- 扣电前先落盘 pending 记录；结算不明或保存失败即停止，不盲目重复扣电。账号独立 JSON 为原子事务记录（目标、待核实扣电、历史结果），并非对原生 YAML 日常配置的替换。
- 识别配方随包提供，首次复制到 config/inventory_extension；只使用包内相对路径，不依赖外部 OCR 进程或开发者安装目录。版本不一致、游戏失去焦点或执行权变化时停止。
- 材料目录已连接，但扩展识别仍是试用，不宣称 97 种全部独立实机验证。游戏更新须重新核对配方，不能忽略版本守卫。

## 测试与依赖

配套测试在独立 zzz-od-test 仓，包括库存计算、原生接口模拟调用、双帧读取、真实 97 项副本计划构建、工厂/设置发现，以及离屏 UI 保存、排序、账号和忙碌保护。测试不创建游戏控制器，不消耗电量，不能代替实机验收。

本改动依赖 OneDragon-Anything/ZenlessZoneZero-OneDragon#2862；配套测试依赖 OneDragon-Anything/zzz-od-test#79。测试仓先合并，主仓后合并。画质 PR OneDragon-Anything/ZenlessZoneZero-OneDragon#2863 独立，不混入库存应用。
