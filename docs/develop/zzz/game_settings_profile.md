# 自动切换游戏画质配置

## 目标

绝区零没有可用的启动参数直接限制帧率。自动化运行时间较长时，用户可以准备两份 Windows 注册表文件：

- **一条龙画质配置**：例如 30 帧、低画质，供自动化运行时使用。
- **正常画质配置**：用户平时游玩时使用的原设置。

启用自动切换后，最外层绝区零自动化负责在运行前导入前者，并在退出时导入后者。内部应用仍按原方式嵌套执行，不会反复导入配置。

## 运行顺序

1. 检查两份文件存在、扩展名为 `.reg`，并确认所有注册表段都位于绝区零的国服或国际服配置键下。
2. 如果游戏已经运行，先请求游戏正常退出，并等待窗口消失。
3. 导入一条龙画质配置，再开始自动化。后续进入游戏流程会按原有方式启动客户端。
4. 自动化正常结束、失败或被用户停止时，等待最外层应用退出。
5. 再次正常关闭游戏，等待游戏保存并退出，然后导入正常画质配置。

必须先关闭游戏再导入：运行中的游戏可能继续使用内存里的旧配置，并在退出时覆盖注册表。自动切换因此会在开始时重启游戏，并在结束时关闭游戏。

## 配置与界面

开关和两份文件路径属于绝区零的一条龙全局配置，保存在 `one_dragon.yml`。一条龙运行界面提供以下设置：

- 自动切换游戏画质配置
- 一条龙画质配置文件
- 正常画质配置文件

文件选择时立即校验内容；运行前还会再次校验，防止文件在选择后被替换。

## 安全边界

注册表文件只允许包含以下键及其子键：

- `HKEY_CURRENT_USER\Software\miHoYo\绝区零`
- `HKEY_CURRENT_USER\Software\miHoYo\ZenlessZoneZero`

删除整个注册表键的段会被拒绝。导入通过参数列表调用 Windows 自带的 `reg.exe`，不拼接 shell 命令。项目不内置或猜测具体画质字段，避免游戏更新后写错配置。

## 失败处理

- 文件无效、游戏无法正常关闭或一条龙画质导入失败时，不启动自动化。
- 一条龙画质导入失败后，仍会尝试导入正常画质配置。
- 自动化退出时恢复失败，会记录明确错误，并把最外层应用结果标记为失败。
- 程序被强制结束或系统断电时无法执行退出流程；用户可手动双击正常画质 `.reg` 文件恢复。
