# 前台点击窗口归属

前台鼠标使用桌面坐标。游戏窗口被其他窗口遮挡时，坐标仍在游戏范围内，但实际接收点击的窗口可能已经改变。

`PcControllerBase._foreground_click` 使用绑定游戏窗口句柄校验前台和点击点的顶层窗口。需要时临时提升游戏窗口并调用原有激活方法；鼠标移动后、按钮按下前再次校验。归属失败返回 `False`，由原有操作链决定后续处理，不发送按钮输入。

临时置顶在退出时恢复，已有置顶属性保留。窗口销毁或句柄被另一线程、进程复用时，跳过恢复。输入异常仍释放 ALT 和鼠标按钮，并保留原异常。

游戏坐标、识别和操作链不变。后台 PostMessage 和手柄入口不使用此路径。对应测试位于独立测试仓库的 `test/one_dragon/controller/test_owned_foreground_click.py`，覆盖遮挡、移动后焦点或像素归属改变、销毁、句柄复用和异常恢复。

自动战斗的 `btn_tap` 和 `btn_press` 也可能使用鼠标按键。前台键鼠控制器发送鼠标攻击前，对当前鼠标位置使用同样的窗口归属校验与临时提升；不移动鼠标、不改变攻击键或持续时间。已按下按钮的释放仍执行，避免因后续窗口变化留下按住状态。普通键盘、后台和手柄保持原路径。
