# 拖拽按下等待

PC 控制器的 `drag_to` 提供可选 `press_time`，表示鼠标左键按下后、开始移动前的等待秒数。等待独立于 `duration`，不缩短原有移动过程及终点停顿。

默认值为 0：前台按下后立即移动，后台保留至少 0.02 秒等待。显式传值时，前台在按下后等待该时长；后台等待该时长与 0.02 秒中的较大值。

贝果的物资拖拽显式使用等待，具体时长和流程见[贝果应用说明](../zzz/application/bagel.md)。其它调用不传参数时保持原行为。时序测试通过替换鼠标输入与计时接口，验证公开入口的参数传递，以及按下、等待、移动、松开的顺序；这些测试不证明游戏内抓取一定成功。
