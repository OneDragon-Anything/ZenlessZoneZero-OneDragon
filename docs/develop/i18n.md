# Internationalization

The application uses the existing gettext catalogs under `assets/text`.

- Supported language codes are `zh-CN`, `en`, and `vi`.
- `zh-CN` maps to the historical gettext directory `zh`.
- `gt()` keeps compatibility with existing Chinese msgids.
- New code may use `tr()` with the semantic keys defined in `i18_utils.py`.
- Missing Vietnamese entries fall back to English.
- `CustomConfig.ui_language` stores the selected code and accepts the legacy `zh` value.
- Qt pages subscribe to the language-change callback and refresh navigation labels and registered page text without restarting.

When adding a user-facing string, add the same msgid to `zh.po`, `en.po`, and `vi.po`, then rebuild the corresponding `.mo` files. Do not use localized display text as program state; use the combo-box user data instead.

Run `python tools/ci/extend_i18n_catalog.py` after adding a batch of UI strings, then run `python tools/ci/validate_i18n.py` and `python tools/ci/compile_i18n.py`. The validator checks catalog parity and named placeholders before the catalogs are compiled.
