# 按键禁用（技能按钮变 X）

> 通用机制，不属于某一个玩法。画面元素见 [战斗画面](../screens/战斗画面.md)，识别实现见 [自动战斗](../../develop/zzz/auto_battle.md)。

## 是什么

战斗画面右下角有三个技能按钮：普通攻击、特殊攻击、终结技。某些情况下按钮**位置不变、图标变成灰色的 X**，这时按对应的键不生效。三个按钮可以同时禁用，也可以只禁用其中一两个。

## 实测记录

薇斯珀一战里三个按钮依次被禁（2026-10-26 实机录制，具体副本待确认）：

| 按钮 | 进入禁用 | 解除 | 时长 |
|---|---|---|---|
| 终结技 | 12.558s | 22.333s | 9.775s |
| 普通攻击 | 16.289s | 22.333s | 6.044s |
| 特殊攻击 | 16.289s | 22.333s | 6.044s |

终结技先禁、普攻和特殊攻击后禁，三个一起解除。这段时间里玩家仍能正常操作角色（移动、普攻之外的切人等），只是这三个键不生效。

三个按钮的禁用态：按钮原位不变，中心换成灰色 X，外圈状态另外算。图标本身在 `assets/template/battle/btn_ban_normal_attack/`、`btn_ban_special_attack/`、`btn_ban_ultimate/` 三个目录里（各含 `raw.png` 与 `mask.png`），直接看 `raw.png` 就是禁用图标的原样。

## 禁用和可用不是互斥关系

按钮外圈的进度环（能量环、冷却环）和中心的 X 图标是两个独立的画面元素。禁用期间外圈可以照常显示，所以「按键可用-X」和「按键禁用-X」两个状态**可以同时成立**。

写自动战斗条件时不要假设它们互斥，也不要用「没识别到禁用就等于可用」这种反推。

## 禁用起止可判定

禁用有明确的开始和结束。自动化侧记录的是**首次识别到禁用的时间**，禁用期间不刷新，所以「已经禁用了多久」可以直接查。具体状态名和用法见 [自动战斗 · 按键禁用状态](../../develop/zzz/auto_battle.md)。
