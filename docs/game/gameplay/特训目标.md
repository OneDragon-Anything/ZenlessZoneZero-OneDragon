# 特训目标

## 定位

「特训目标」是快捷手册「训练」页中的统一养成入口。玩家选定代理人、音擎等培养目标后，页面会把仍然缺少的养成材料和推荐的驱动盘整理到同一列表，并提供直达对应副本的「前往」按钮。

该入口在 2.6 版本加入，官方说明见[《绝区零》2.6版本更新说明](https://www.hoyolab.com/article/43642066)。

## 页面信息

- 右上角资源栏显示当前电量、储蓄电量和以太电池。
- 材料按培养用途分组，例如「技能」；每一项显示材料名称、当前数量与目标需求、单次可选电量范围和「前往」。
- 页面顺序由游戏当前的培养目标决定。列表顶部是游戏此时优先推荐补充的材料。
- 材料目标完成后，列表下方仍会显示推荐驱动盘；实拍状态中第一项为「迅脊与裂爪」，第二项为「锐牙与钝斧」。具体推荐会随培养目标和游戏版本变化。

## 电量与副本对应关系

| 页面显示 | 对应玩法 | 单次消耗 |
|---|---|---|
| `20-100` | 实战模拟室 | 每张怪物卡 20 电量，可选 1～5 张 |
| `40-80` | 专业挑战室 | 普通模式 40 电量；燃竭模式 80 电量 |
| `60`，位于「驱动盘」分组 | 区域巡防 | 60 电量 |
| `60`，位于材料分组 | 恶名狩猎的深度追猎 | 60 电量 |

上述对应关系来自 1080p 实机页面和「前往」后的实际落点。专业挑战室的 `40-80` 项在电量足够时可使用燃竭模式；电量不足 80 但不少于 40 时，可关闭燃竭模式执行普通挑战。

## 一次消耗循环

1. 打开快捷手册「训练」页并选择「特训目标」。
2. 从列表顶部找到当前第一项未完成材料；若材料均已完成，则使用第一项推荐驱动盘。
3. 点击该项「前往」，确认传送后进入对应副本。
4. 按当前电量选择该副本允许的最大消耗档位并完成一场战斗。
5. 战斗结束后重新查看「特训目标」。材料数量、缺口和推荐顺序可能已经变化，不能沿用上一场的选择。
