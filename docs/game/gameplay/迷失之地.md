# 迷失之地(零号空洞·战斗肉鸽)

绝区零 1.4 版本上线的**战斗肉鸽(Roguelike)**玩法,零号空洞三大分支之一(另两个:枯萎之都 / 断层之谜)。局内逐层推进、击败首领;局外靠「调查进度等级」长线积累奖励。本文写**玩家视角机制**;画面细节见 [screens/迷失之地](../screens/迷失之地.md),自动化编排见文末附录。

> 信息源:网络攻略(萌娘百科为主,经浏览器实读)+ 项目代码反推 + 本轮实拍。每条标置信度:**【官方】**/`【多源】**/`【单源】**/`【待确认】**;代码确认的标 **【代码】**。

## 这是什么

- **定位**:战斗肉鸽,无走格子,实时战斗 + 局内构筑(鸣徽/武备/卡牌)。`【多源】`
- **位置**:斯科特哨站(零号空洞上方枢纽)→ 零号空洞 → 迷失之地;也可「快捷手册-作战」直达。**【代码】** `LostVoidApp` 经 `TransportByCompendium('作战','零号空洞','迷失之地')` 传送。
- **解锁前置**:先解锁零号空洞(主线第二章间章「非常任务」+ 通关稳定节点第十防线)→ 完成代理人秘闻「洞中谍 上」→ 接「迷失之地」系列委托 → 完成特殊行动剧情,开启「战线肃清」。`【多源】`
- **副本分类(随版本扩充)**:
  - **战线肃清**(1.4 起):5→6 个难度,选「调查战略」+「周期增益」。
  - **特遣调查**(2.0 起):每周 UP 代理人,代理人专属武备「战术棱镜」(α/β 分支,锁定整局)。
  - **矩阵行动**(2.6 起):特遣调查基础上加「协战代理人」(后台释放支援技),主战武备改为战术棱镜方案;每周 UP 两位主战 + 一位协战。**周常轮替玩法** —— 入口仅「矩阵行动周」显示(顶部多出「街区」tab → 矩阵行动入口),非矩阵周入口看不到它 → `mission_name='矩阵行动'` 在非矩阵周跑不动,等每周 reset 轮换(入口「周期剩余时间」倒计时)。`【多源】`
  - **【代码】** 由 `LostVoidConfig.mission_name` 选择(`战线肃清` / `特遣调查` / `矩阵行动`),app 按之分支走不同入口流程。

## 玩法目标

- **局内目标**:逐层推进,每层末击败「战斗·道中危机」(道中首领) → 经「挚交会谈」→ 击败「战斗·终结之役」(最终首领)即完成本次挑战。`【多源】` **【代码】** `LostVoidRegionType.ELITE` / `BOSS`。
- **局外长线**:通关获「阴影结晶数据」提升「调查进度等级」(原执照等级,2.1 已至 Lv.180),等级奖励含菲林 / 丁尼 / 高保真母盘 / 邦布券 / 家政扫荡券。`【官方】`
- **零号业绩(=「业绩点」)**:零号空洞整体周常货币,**每周地图获取上限 900 点**,斯科特哨站 NPC「卡斯珀」处兑换(原装母带 > 邦布券 > 限购丁尼 > 代理人经验)。`【多源】` **【代码】** `run_record.eval_point_complete`、结算模板 `奖励-零号业绩`。
- **丁尼**:新艾利都基础货币(类比摩拉/信用点),通关直接掉落。`【多源】` **【代码】** 结算模板 `奖励-丁尼`。
- **周期奖励**:零号空洞每周常规奖励结算次数,**上限 45 次**(每击败一个区域首领算 1 次;完整通关 3 层 = 3 次,每周约 15 场拿满)。`【多源】` **【代码】** `run_record.is_finished_by_week`、`add_complete_times`。
- **悬赏委托**:额外周常,进度 `xxxx/8000`(达 8000/8000 视为完成,可领全部奖励)。`【代码】** `_wait_for_lost_void_entry` → `check_bounty_commission_before` 用 OCR `'8000'` 出现次数判定(1 次=未完成、2 次=完成)。

## 经济循环(核心)

```
局内循环(每层):
  区域战斗/挑战 ──产出──> 齿轮硬币 + 鸣徽/武备/卡牌
        │                          │
        │                          └─装载/升级─> 武备强化(同流派鸣徽 2/4/6 → 2/3/4 级)
        │
        └──邦布商店──(花齿轮硬币)──> 买鸣徽/卡牌 + 刷新(50/100/200/300)
        │
        └──路径迭换──(花定位卡)──> 刷新地图样式,改路
        │
        ▼
  道中危机(ELITE)─胜─> 挚交会谈(补给/玛琳刷图)─> 终结之役(BOSS)─胜─> 结算

局外循环(每周):
  通关结算 ──> 周期奖励次数(45/周)+ 零号业绩(900/周)+ 丁尼 + 阴影结晶数据
        │
        └─阴影结晶数据─> 调查进度等级↑ ─> 等级奖励(菲林/母盘/邦布券/扫荡券)
```

**关键循环特征**:局内是「**战斗产出资源 → 资源转化为战力(鸣徽升武备 / 商店采购)→ 推进更深**」的滚雪球;局外是「**通关 → 调查进度等级 → 长线奖励**」的周积累。构筑质量(鸣徽/武备流派协同)决定能推进的深度。

## 核心机制

- **构筑(Roguelike 核心)**:鸣徽分流派,武备靠装同流派鸣徽升级;好构筑 = 同流派协同 → 战力滚雪球。**【代码】** 选择优先级由 `artifact_priority` / `artifact_priority_2` / `artifact_priority_new`(优先 NEW)/ `region_type_priority` 配置,战斗中还会按当前队伍代理人类型**动态追加优先级**(`append_agent_type_priority`)。
- **特遣调查 / 矩阵行动 的「战术棱镜」锁定**:选了某代理人/某分支后,其余本局不可再得 → 选角即定路线。`【多源】` **【代码】** `GEAR_BRANCH`、协战代理人属性会被追加为鸣徽第一优先级。
- **区域类型驱动**:每层由若干「区域类型」组成,类型决定产出(硬币/鸣徽/武备)与玩法(战斗/挑战/事件/商店)。完整区域类型表见下「子玩法」。
- **挚交会谈的多角色**:每层 Boss 战前的会谈区,可遇 NPC(阿援 / 玛琳 / 奥菲莉亚 等),功能含刷图(玛琳-定位卡)、商店、补给。`【代码】** `move_after_interact` 按 NPC 名做不同移动(避开障碍)。
- **以太活性 / 难度**:特遣调查高活性下不再提供商店与生命恢复、所有刷新次数变 1(1.6 起部分模式统一刷新为 1 次)。`【多源】`

## 子玩法(区域类型 + 交互)

每层由以下区域类型构成(玩家视角作用,`【多源】`;代码区域类型见 `LostVoidRegionType`):

| 区域类型 | 玩家视角作用 | 对应画面 / 交互 |

## 日常 / 周期

- **周期奖励结算**:每周 **45 次**(每击败一个区域首领 = 1 次)。`【多源】` **【代码】** `is_finished_by_week`。
- **零号业绩**:每周地图获取上限 **900 点**。`【多源】`
- **悬赏委托**:每周 `xxxx/8000`,达 8000 可领全部。`【代码】**
- **调查进度等级**:无周限,有等级上限(2.1: Lv.180)。`【官方】`
- **特遣调查 / 矩阵行动**:每周 UP 代理人轮换(矩阵行动每周 UP 两主战 + 一协战)。`【官方】`/`【单源】`

## 入口

大世界 → 快捷手册(作战)→ 零号空洞 → 迷失之地 → 入口画面(周期/常规)→ 选副本 + 调查战略 + 周期增益 + 编队 → 出战 → 层间移动。**【代码】** `LostVoidApp` 节点链:`tp_to_lost_void` → `wait_lost_void_entry` → `check_bounty_commission_before` → (按 mission 分支:矩阵行动编队 / 战略+增益+编队) → `deploy` → `run_level`(循环)→ `after_complete` → 全部领奖 → `back_at_last`。

## 附录:自动化实现(代码编排,非玩法)

**app**:`LostVoidApp`(`src/zzz_od/application/hollow_zero/lost_void/lost_void_app.py`),`app_id=lost_void`。**配置**:`LostVoidConfig`(副本/运行参数)+ `LostVoidChallengeConfig`(挑战战略:鸣徽优先级 / 武备优先级 / 调查战略 / 刷新次数 / 编队 / 追新模式 等,`config/lost_void_challenge/*.yml`)。

**主流程节点链**:
1. `init_for_lost_void` — 查 `is_finished_by_day`;加载 lost_void 数据 / 识别模型 / 自动战斗。
2. `check_initial_screen` — 大世界直接继续;否则 `tp_to_lost_void`(`TransportByCompendium`)。
3. `wait_lost_void_entry` — 等入口画面(周期/常规)。
4. `check_bounty_commission_before` — OCR `8000` 次数判悬赏委托完成度;未完成按 `mission_name` 分支。
5. **矩阵行动分支**:`matrix_*` 系列节点(预备编队 → 选主战/协战代理人 → 开始挑战)。
6. **常规分支**:`goto_mission_screen` → `check_for_mission`(特遣调查额外识别 UP)→ `open_strategy_list` → `choose_strategy`(追新模式 CV / OCR)→ `choose_buff`(周期增益)→ `check_predefined_team` → `deploy`。
7. `load_auto_op` → `run_level`(委托 `LostVoidRunLevel`,按层循环)。
8. `STATUS_COMPLETE` → `after_complete`(`add_complete_times`)→ 回 4;`STATUS_ENOUGH_TIMES` → `open_reward_list` → `claim_all` → `back_at_last`。

**层间移动 `LostVoidRunLevel`**(`lost_void_run_level.py`):核心循环 = `非战斗画面识别`(YOLO `detect_to_go` 找 感叹号/白点/下层入口,按优先级移动)→ `try_interact`(interact F)→ `handle_interact`(**按画面路由**:武备选择→`LostVoidChooseGear` / 通用选择→`LostVoidChooseCommon` / 邦布商店→`LostVoidBangbooStore` / 路径迭换→`LostVoidRouteChange` / 抽奖机→`LostVoidLottery` / 挑战结果→结算 / 否则对话/黑屏兜底)→ `after_interact`。战斗走 `init_auto_op` → `in_battle`(自动战斗 + 识别脱战)。失败兜底:`handle_find_target_fail` → `push_error` → `fail_exit_lost_void`。

**通用选择决策(`LostVoidChooseCommon`)**:OCR 标题定子态与需选数 → 四层选择策略(NEW → 同流派优先级 → 答题兜底 → 盲点兜底),选满 N → 点确定(解析按钮 `(x/y)` 计数判断选满)。
