# 实战模拟室

## 这是什么

实战模拟室是消耗电量获取代理人和音擎养成材料的常驻玩法。玩家可在 HIA 俱乐部进入，也可从快捷手册的“训练”页前往。

玩法分为基础材料、代理人晋升、代理人技能、音擎改装和自定义模板：

- 基础材料：调查员记录、音擎经验、丁尼和驱动盘经验。
- 代理人晋升：各专长代理人的认证章。
- 代理人技能：各属性的技能芯片。
- 音擎改装：各专长音擎的突破组件。
- 自定义模板：把不同材料的卡片组合到同一场挑战中。例如，两张调查员记录卡片加一张丁尼卡片，会在一场战斗中同时获取这两类材料。

## 核心循环

```text
选择材料副本 → 选择卡片数量 → 编队并战斗 → 结算材料 → 继续刷取或离开
```

卡片是一次材料产出的单位，每张消耗 20 电量并在结算页生成对应的奖励。例如，选择三张卡片会消耗 60 电量，并获得三张卡片对应的材料。结算页右侧以最多四列、两行的格子显示每张卡片获得的材料图标和数量，同一种材料可能占多个格子。

`UP` 表示该奖励格受到活动或其他增益，实际材料数量会增加。按材料数量运行时直接累计结算页显示的增益后数量，不再额外乘算。结算页可选择“再来一次”直接重复当前方案，也可选择“完成”返回副本选择页。

## 材料数量与合成

同系列的认证章、技能芯片和音擎组件通常分为三个等级。三个低一级材料可合成为一个高一级材料；反向分解时，一个高一级材料可得到三个低一级材料。因此，准备高等级材料时，可以把已有低级材料按 3:1 逐级折算。

调查员记录、音擎经验、丁尼和驱动盘经验没有这套 3:1 合成规则，只按结算页实际获得的目标材料计算。

示例：目标是“特化以太芯片”时，“进阶以太芯片”按 3 个折算 1 个，“基础以太芯片”按 9 个折算 1 个；中级材料与低级材料合成出的中级材料可以合并计算。

## 决策点

- 想减少进出副本次数时，选择更多卡片。
- 想精确控制剩余电量时，选择较少卡片。
- 只关心实际拿到的最高级材料时，不计入低级材料。
- 计划之后会合成低级材料时，把同系列低级材料一起折算，能减少多刷的次数。
- 自定义模板会在同一场混合不同材料，同品质图标不能只靠结算页颜色区分，不适合按单一材料数量自动停止。
