# 合成电池(以太电池合成)

把「会溢出的电量」转化为「可储存、可批量使用的以太电池」的体力转化玩法。**合成电池**是体力计划(`ChargePlanApp`)的一个特殊计划分类——固定消耗 60 电量合成 1 个以太电池囤积。

## 这是什么

**以太电池** = 打包的电量道具:
- **使用**获得 **60 电量**(= 体力)。
- 也可**直接扫荡**一次「实战模拟室」或「区域巡防」,跳过战斗直接领奖。
- 是电量的「储存形式」,不会随时间自动恢复、无溢出问题。

**合成电池**玩法的意义:电量上限 240、会自动恢复,接近上限不消耗就**溢出浪费**。通过合成把电量转成电池囤积,需要时再转回电量或直接扫荡高收益副本。

> 2.5 版本新增合成路径:用「储值电卡」+ 电量合成以太电池;维多利亚家政券 2.5 后等比例转化为以太电池(区域巡防的家政券机制同步移除)。

## 玩法目标

**囤积以太电池**,避免电量溢出浪费。囤积后用于:
- 高收益副本(双倍活动 / 恶名狩猎)前补电量;
- 直接扫荡实战模拟室 / 区域巡防(跳过战斗领奖)。

## 核心资源

| 资源 | 作用 | 上限/来源 |
|---|---|---|
| 电量 | 体力,进本/合成消耗 | 上限 240,自动恢复(+N/小时),溢出浪费 |
| 储蓄电量 | 额外电量储备 | 上限 2400 |
| 以太电池 | 使用=60电量 / 扫荡一次 | 可合成囤积;使用或扫荡后消失 |
| 储值电卡 | 合成以太电池的素材 | 2.5 新道具;来源见[下节](#储值电卡来源采集途径) |
| 丁尼 | 游戏货币 | 合成消耗少量 |

## 经济循环(核心)

```
电量(会溢出) ──[合成]──> 以太电池(可长期储存) ──[使用]──> 电量(需要时)
                                            └──[扫荡]──> 实战模拟室/区域巡防 奖励
```

**主循环**:把自动恢复、会溢出的电量,转化为不溢出的电池储存,需要时再释放。本质是**电量的时间搬运**(现在多余 → 存起来 → 未来用)。

## 合成机制(live 实证 2026-07-22)

- **入口**:快捷手册资源栏点「以太电池」图标 → 弹资源详情 → 点「[获取]合成」→ [道具处理](../screens/道具处理.md)(合成页)。
- **单次消耗**:1 个以太电池 = **60 电量 + 100 储值电卡 + 丁尼**(实拍合成确认框)。
- **数量**:右侧 `-`/滑块/`+` 可调合成数量,默认 ×1。
- **素材不足**:合成页显示「合成素材不足」提示,无法合成。
- 也可从仓库-材料道具页 → 「道具处理」按钮进入同一界面。

## 储值电卡来源(采集途径)

2.5 新道具,共 4 个获取途径(按自动化适配状态排序):

| 途径 | 兑换条件 | 限额 | 自动化状态 |
|---|---|---|---|
| 德丰大押·珍宝商铺(随便观) | 250 百通宝/张 | 月刷 10 次 | ✅ `suibian_temple_pawnshop` 泛化 OCR 已支持(配置 `pawnshop_omnicoin_priority` 勾选) |
| 后勤哨站商店(哨站后勤处 + 站点物资处) | 120 零号业绩/张 | 月刷 10 次 | ❌ 无应用无界面文档;入口线索=快捷手册「快速界面-后勤商店」/迷失之地奖励页底栏「哨站后勤」tab |
| 信号残响商店 | 50 信号残响/张 | 月刷 10 次 | ❌ 零覆盖(信号残响来源=母带调频) |
| 后备电量合成 | 60 电量 + 丁尼/张 | 日上限(电量恢复节奏) | ⚠️ 存疑:与 live 实拍方向相反(实拍=电卡+电量→电池),第三方攻略描述可能指旧版机制或转述错误,不采信 |

- 电卡的核心用途:合成以太电池;以及实战模拟室/区域巡防的**快速扫荡**(消耗 1 张=跳过战斗直接领奖,等价 60 电量,需把副本电量消耗档位调至 60)。

## 以太电池来源(除合成)

- 丽都城募(大月卡/通行证)等级奖励;
- 零号空洞-迷失之地通关;
- 维多利亚家政券 2.5 后等比例转化;
- 储值电卡合成(本玩法)。

## 日常 / 周期

**无周期限制**,随电量恢复节奏合成——电量接近 240 上限、本日无消耗计划时,合成避免溢出。

## 入口

大世界 → 右上「快捷手册」(需 pc_alt) → 资源栏点「以太电池」→ 「[获取]合成」→ 道具处理。

## 附录:自动化实现(代码编排,非玩法)

- **计划分类**:体力计划 `ChargePlanApp` 新增「合成电池」`category_name`,固定预估 60 电量;界面隐藏配队/副本类型控件;不参与咖啡匹配(合成电池不消耗体力打本)。
- **分流**:传送节点按 `category == 合成电池` 直接走 `ExchangeEtherBattery`,不经 `TransportByCompendium`(不需传送到副本)。
- **`ExchangeEtherBattery` 节点链**:点以太电池 → OCR 点「[获取]合成」→ 等道具处理 → 检查素材(详情标题 OCR 以太电池 + 检测合成素材不足) → 点合成 → 合成确认 → 获得弹窗 → 兑换完成;`plan_times` 控制合成次数,每次 ×1 循环。
- **容错**:合成素材不足 / 未找到以太电池 → 计划失败标记跳过,**不阻断**体力计划后续流程。
- 详见 [charge_plan 开发文档](../../develop/zzz/application/charge_plan.md)。
