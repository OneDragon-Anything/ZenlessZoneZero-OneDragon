# 战斗系统(玩法)

绝区零的核心战斗机制。本页只讲**通用共性机制**(所有战斗玩法共用),作为理解自动配队 / 自动战斗的依据。个别角色的专属机制(如某某角色的独有架势 / 染色 / 能量条)不展开——那是角色百科内容,查 [米游社 WIKI](https://baike.mihoyo.com/zzz/wiki/channel/map/66/68) 或 [萌娘百科](https://zh.moegirl.org.cn);只在**代码用到时**在本页点到。

战斗画面识别见 [战斗画面.md](../screens/战斗画面.md)。

## 这是什么

战斗是绝区零绝大多数玩法(式舆防卫战 / 恶名狩猎 / 迷失之地 / 各类副本)的核心:3 人小队实时切人打怪,靠 **属性克制 + 异常积蓄 + 失衡击破** 三条机制链路输出伤害。配队围绕这三条链路 + 角色职业搭配展开。

## 三条输出链路

### 1. 属性克制(直伤队核心)

- **7 种属性**:电、以太、物理、火、冰、风(3.0 引入)、流明(对应代码 `DmgTypeEnum`)。
- **克制(弱点)**:敌人对该属性抗性 **-20%**,直伤更高(伤害数字白色)。
- **抗性**:敌人对该属性抗性 **+20%**,直伤更低(伤害数字变灰)。
- 非克制非抗性:抗性 0,正常伤害。

> **配队依据**:尽量用敌人**弱点属性**的输出角色,避开**抗性属性**。脚本据此给候选队评分(见末尾「自动配队评分」)。

来源:[NGA · 绝区零数据机制导论](https://bbs.nga.cn/read.php?tid=40893992)。

### 2. 异常积蓄 + 紊乱(异常队核心)

- **异常积蓄**:用同属性攻击持续打敌人,积累「异常值」(怪物血条右侧进度条);攒满触发该属性的**异常效果**(各属性效果不同,分持续伤害类 / 单次伤害类 / 控制类,具体查 WIKI)。
- **紊乱(Disorder)**:对已处于某异常状态的敌人,再施加**另一种属性**的异常 → 覆盖原状态,触发**紊乱**,额外结算一次伤害。
  - 异常队靠快速挂多种异常反复触发紊乱打伤害(混伤,以异常为主、直伤为辅)。
  - 异常伤害受「异常精通 + 攻击力 + 异常掌控」影响,**不受暴击影响**(培养方向与直伤角不同)。

> 注意游戏内正式术语是「**紊乱**」(Disorder);风属性版的紊乱叫「**乱流**」(风专属别名,见下「染色」),"紊流"则是误写。

来源:[游民星空 · 全属性异常效果一览](https://www.gamersky.com/handbook/202407/1784391.shtml)、[TapTap · 紊乱机制解读](https://www.taptap.cn/moment/591659398095440330)。

### 3. 失衡 + 连携技(击破队核心)

- 攻击积累敌人**失衡值**(血条下方进度),满后敌人进入「失衡状态」,期间受到的伤害大幅提升。
- 失衡期间触发**连携技**(角色大招演出),是爆发输出窗口。
- **击破**职业负责快速打失衡,把队伍"抬"进连携爆发期。

## 染色(风 / 流明异常的特殊机制)

风、流明是较新的特殊异常属性,有专属异常交互(代表角色:风=维琳娜、流明=蕾米埃尔,角色技能详见 WIKI),是当前版本异常队核心。

- **风属性**:异常体系为**风化**(持续伤害)→ **浸染 / 染色**(接触其他属性时提升风 + 该属性伤害)→ **乱流**(风化与其他属性异常共存时触发爆炸,风版紊乱)。乱流靠**队友的异色异常**触发。
- **流明属性**:**可变属性**——流明异常会随队友属性变化(与风属性队友 → 算风伤,与物理 → 物伤,与以太 → 以太伤)。

**风 + 流明同队**:流明因风属性队友而变风伤 → 双方都打风,**没有异色异常可触发风乱流**。配队评分据此对两者做不对称处理:

- 风异常的乱流染色源**不能是流明队友**(流明会变风,非异色)→ 评分时 `WIND` 排除 `LUMIFLUX` 队友。
- 流明可变,能吃任何队友属性(含风)→ 评分时 `LUMIFLUX` 不排除队友。

见 `shiyu_defense_team_utils.py:_calc_team_score` 染色分支。

来源:[游侠 · 维琳娜技能介绍](https://m.ali213.net/news/gl2606/1783305.html)、[4399 · 蕾米埃尔全面解析](https://www.4399.com/pcgame/topic/53681368.html)、[NGA · 蕾米埃尔绑定维琳娜讨论](https://bbs.nga.cn/read.php?tid=47024817)。

## 职业系统

每个代理人有**职业**(`AgentTypeEnum`),决定战斗定位:

| 职业 | 定位 | 配队评分角色 |
|---|---|---|
| 强攻(ATTACK) | 直伤输出主力 | 输出(按属性克制评分) |
| 命破(RUPTURE) | 直伤输出(另一套体系) | 输出 |
| 异常(ANOMALY) | 靠异常积蓄 / 紊乱打伤害 | 输出(异常倍率;风/流明走染色分支) |
| 击破(STUN) | 打失衡触发连携 | 辅助(对齐最强输出计分) |
| 支援(SUPPORT) | 增伤 / 治疗 / buff | 辅助 |
| 防护(DEFENSE) | 护盾 / 生存 | 辅助 |

## 虚狩

**虚狩**是新艾利都调查员的**最高荣誉称号**(由市长授予,表彰镇压空洞的极大贡献),**不是职业也不是属性**,而是剧情设定上的头衔。当前虚狩级代理人(对应代码 `VOID_HUNTER_AGENT_ID_LIST`):仪玄(`yixuan`)、星见雅(`hoshimi_miyabi`)、叶瞬光(`yeshunguang`)、蕾米埃尔(`remielle`)。

> 代码里 `VOID_HUNTER_*` 命名是"虚狩"的直译(早期被误称为"虚无猎人")。虚狩角色通常机制 / 数值更强,脚本配队给虚狩角色 **1.2 倍评分加权**。该列表**硬编码**,游戏新增虚狩角色时需手动补(后续可考虑下沉到 `Agent` 数据字段派生)。

来源:[萌娘百科 · 虚狩](https://zh.moegirl.org.cn/zh-cn/%E8%99%9A%E7%8B%A9)。

## 关联:自动配队评分(代码)

式舆防卫战自动配队(`shiyu_defense_team_utils.py:DefenseTeamSearcher` / `select_teams`)用上述机制给候选预备编队打分,选**总分最高且两阶段代理人不重复**的组合:

- **输出角色(强攻 / 命破 / 异常)**:按属性对弱点 / 抗性的契合度评分。代码用 `1.3 / 0.7`(异常 `1.69 / 0.49`)——**这是评分权重,不是真实 ±20% 伤害倍率**;放大克制 / 抗性的分差以便排序。
- **辅助角色(击破 / 支援 / 防护)**:按「对齐队内最强输出」计入,每个辅助贡献 = 最强输出分(`sum(output) + max(output) × 辅助数`)。
- **虚狩角色**:1.2 倍加权。
- **风 / 流明异常**:走染色分支(看队友异常属性)。
- 普通节点 2 个半场 / 多间模式全部未完成房间的队,代理人 ID 不能重复。

配队的完整玩法流程见 [式舆防卫战.md](式舆防卫战.md);扫描 / 点击选队的自动化实现见相关 application / operation 代码。
