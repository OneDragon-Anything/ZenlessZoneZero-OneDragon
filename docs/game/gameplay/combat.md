# 战斗系统

## 机制

- 实战模拟室、区域巡防、专业挑战室和恶名狩猎等挑战会经过编队、出战、战斗和结算。
- 部分挑战目标包含通关用时要求。自动化可以用用户设置的战斗时限近似判断当前队伍是否无法达到目标用时，但这不等同于识别结算评级。
- 体力计划提供的 S 级时限预设为：实战模拟室 120 秒、区域巡防 120 秒、专业挑战室 180 秒、恶名狩猎 300 秒。预设按各玩法的 S 级通关目标取值，仍允许玩家按队伍情况修改。
- 战斗过程中退出或战斗失败不会算作正常通关，只有进入正常结算流程后才增加体力计划的已运行次数。

## 流程与决策点

1. 在副本入口选择预备编队并出战。
2. 战斗画面出现后开始自动战斗；选队和加载阶段不属于实际战斗时间。
3. 敌人被击败后进入正常结算；角色全灭会进入失败结果。
4. 战斗中可以打开暂停菜单，选择退出战斗并确认，随后离开失败结果画面回到当前副本的准备或配置页。
5. 体力计划启用换队时限后，战斗失败或实际战斗时间达到用户设置的阈值会退出。脚本先点击“下一步”进入出战页；如果已经在出战页，则直接选择下一支预备编队。

## 备注

- 体力计划的换队时限不读取结算页的 S 评级；S 级时限按钮只是把玩法对应的目标时间填入配置。
- 预备编队按配置中的顺序使用；到最后一队后不从第一队重新开始。
- 原地换队会保留已选副本和卡片数量；若“下一步”或出战页无法识别，按对应操作失败处理。
