# 贝果计划

进入空洞搜集物资，用安全箱把物资带出，再放进研究站仓库。地图、难度、携带装备和投资分开选。推荐价值与背包、安全箱容量以当前游戏界面显示为准。

自动化怎么跑见 [贝果计划自动化](../../develop/zzz/application/bagel.md)。按钮和识别区域见 [贝果计划画面](../screens/贝果计划.md)。

## 入口与单局

在研究站接待员达塔面前交互，选「出发出发」打开贝果主界面。「前往空洞」进入选图，选地图和难度，再「前往备战」。

备战页分别显示代理人武备、队伍装备、道具价值，以及背包和安全箱占用。全部卸下后仍可进入，但会先提示推荐价值不足、代理人未装备武备、未穿戴队伍装备。高危难度在确认上述提示后，还会进入投资页；投资金额为 0 时可以直接「前往空洞」。

进入后出生位置不固定，打开大地图可以查看当前位置。录像店和白鸽工地地铁站是其中两个复活点。

## 备战物资与仓储

安全箱容量为 2–5 格。仓库容量不固定，上限为 280。两者都以当前游戏界面显示的容量为准，不能固定按安全箱 5 格、仓库 280 计算。

身上携带与仓储库存分开：卸下武备、队伍装备和道具可以转入仓储枢纽，不需要更换代理人阵容。仓库左下「放入仓库」可快速转存左侧背包内容；结算安全箱也使用此按钮入仓。备战右侧已装备物品可快速双击转存，单击仍可查看详情。画面布局与证据见[启动清空相关画面](../screens/贝果计划.md#启动清空相关画面)。

背包装备会影响背包容量。例如，先转存背包内容再卸下背包装备，容量由 50 变为 20；空背包因此从 `0/50` 变为 `0/20`。这两种读数都表示没有背包内容。仓储中的库存仍可出现在备战左侧候选列表，不代表已经带在身上。

尚未确认背包与安全箱同时非空时的批量转存结果，以及不同类型堆叠物部分转出的行为；结算安全箱入仓和满仓现象见[退出与仓库](#退出与仓库)。

备战的「预设组合」可以应用已保存的装备方案，从仓储恢复装备；「覆盖预设」则修改所保存的方案。方案名称由玩家设置，应用前应核对名称。入口与卡片布局见[画面说明](../screens/贝果计划.md#启动清空相关画面)。

## 容器

三种箱子不能用同一套操作：

- 普通箱子：按一次 F 直接打开。
- 小保险箱：长按 F 解锁。
- 大保险箱（电子保险箱）：按 F 进入解锁界面。红圈和黄圈交替向外扩，提示「精确点按 F 或 Space」，进度从 0/4 到 4/4。底部提示解锁时被攻击会打断。成功后进入「电子保险箱」搜查界面。

「助战物资」和「武备箱」不是同一个东西，不能只看箱子外形。

搜查结果里，金币拾取后直接增加携带货币，不占安全箱格子。普通物品可以拖进安全箱。货币在主动退出后还留不留，尚未核对。

## 退出与仓库

局内按 Esc，选「退出」。提示是：「退出后仅保留安全箱内物资，其他物资将全部丢失」。确认后出现 DEFEAT 结算，撤离点显示「无」。主动退出完成，不等于游戏判定成功撤离。时限耗尽同样是 DEFEAT，也可以「继续」进仓库。

结算「继续」进入仓库。左边是本轮携带物和安全箱，右边是仓储枢纽。「放入仓库」把安全箱物资转入仓储。物品并进已有堆叠时，仓库占用件数可以不变。不要把还在安全箱里的东西当成已经入仓。仓库占用达到容量时，安全箱可能仍有物资，画面依据见[满仓状态](../screens/贝果计划.md#满仓状态)。

「返回研究站」回到达塔前的大世界，需要再交互才能打开贝果主界面。从研究站直接打开的仓库没有这个按钮。

仓库可以「批量出售」。底栏变为取消出售、批量选择、确认出售。「批量选择」打开「快速选择」，按类型和稀有度筛选，并显示符合条件的数量。确认筛选后还要再确认一次出售预览，才会真正出售；出售后弹出「获得」齿轮硬币。格上黄点是「建议出售」，不是稀有度。

## 尚未核实

解锁条件、刷新周期、箱子掉落率、失败后重试解锁的完整规则尚不明确。仓满后安全箱有遗留物资时，出售范围与安全腾位方式也尚不明确。
