# 贝果计划

玩家进入空洞搜集物资，用安全箱将物资带出，再转入研究站仓库。地图、难度、携带装备和投资分别选择。推荐价值、背包容量和安全箱容量以当前游戏界面显示为准。

自动化流程见[贝果计划自动化](../../develop/zzz/application/bagel.md)。按钮和识别区域见[贝果计划画面](../screens/贝果计划.md)。

## 入口与单局

1. 在研究站接待员达塔面前，按 F 交互。
2. 选择「出发出发」，打开贝果主界面。
3. 点击「前往空洞」，进入地图选择页。
4. 选择地图和难度。
5. 点击「前往备战」，进入备战页。

备战页分别显示代理人武备、队伍装备和道具的价值。背包和安全箱分别显示占用数。

卸下全部物品后，玩家仍可入场。游戏会先提示推荐价值不足、代理人未装备武备和未穿戴队伍装备。高危难度在确认这些提示后，还会打开投资页。投资金额为 0 时，可以直接点击「前往空洞」。

入场后的出生位置不固定。打开大地图可以查看当前位置。录像店和白鸽工地地铁站是其中两个复活点。

## 备战物资与仓储

安全箱容量为 2–5 格。仓库容量不固定，上限为 280。两者均以当前游戏界面显示的容量为准。

携带物与仓储库存分别记录。玩家可以将已装备的武备、队伍装备和道具转入仓储枢纽。转存这些物品不需要更换代理人阵容。

在仓库中，点击左下「放入仓库」可快速转存左侧背包内容。结算时，安全箱物资也通过此按钮入仓。在备战页，快速双击右侧已装备物品可转存该物品。单击物品会打开详情。画面布局与证据见[启动清空相关画面](../screens/贝果计划.md#启动清空相关画面)。

背包装备会影响背包容量。例如，先转存背包内容，再卸下背包装备，容量由 50 变为 20。空背包读数因此从 `0/50` 变为 `0/20`。两种读数均表示背包内没有物品。

仓储库存可能显示在备战左侧候选列表中。显示在该列表中不表示物品已被携带。

以下行为尚未确认：

- 背包和安全箱同时非空时的批量转存结果。
- 不同类型堆叠物部分转出的行为。

结算安全箱入仓和满仓现象见[退出与仓库](#退出与仓库)。

备战页的「预设组合」可以应用已保存的装备方案，从仓储恢复装备。「覆盖预设」会修改已保存的方案。方案名称由玩家设置，应用前需要核对名称。入口与卡片布局见[画面说明](../screens/贝果计划.md#启动清空相关画面)。

## 容器

三种箱子使用不同的交互方式：

| 容器 | 交互方式 |
| --- | --- |
| 普通箱子 | 按一次 F，直接打开 |
| 小保险箱 | 长按 F 解锁 |
| 大保险箱（电子保险箱） | 按 F，进入解锁界面 |

电子保险箱解锁界面中的红圈和黄圈交替向外扩张。界面提示「精确点按 F 或 Space」，进度从 0/4 增至 4/4。底部提示解锁时受到攻击会被打断。解锁成功后，游戏打开「电子保险箱」搜查界面。

「助战物资」和「武备箱」是不同的交互目标。仅凭箱子外形无法区分两者。

搜查面板打开时受到攻击会关闭面板。玩家可以重新按 F 打开容器。是否重新搜查或直接退出，由玩家或自动化策略决定。

拾取搜查结果中的金币会直接增加携带货币，不占安全箱格子。普通物品可以拖入安全箱。主动退出后是否保留携带货币，尚未核对。

## 退出与仓库

1. 在局内按 Esc，打开暂停菜单。
2. 选择「退出」。
3. 核对提示：「退出后仅保留安全箱内物资，其他物资将全部丢失」。
4. 确认退出。

主动退出后，游戏显示 DEFEAT 结算，撤离点为「无」。完成主动退出不表示游戏判定成功撤离。时限耗尽也会显示 DEFEAT 结算。

在结算页点击「继续」可进入仓库。仓库左侧显示本轮携带物和安全箱，右侧显示仓储枢纽。点击「放入仓库」可将安全箱物资转入仓储。

物品合并到已有堆叠时，仓库占用件数可能不变。安全箱中仍有物资时，这些物资尚未入仓。仓库占用达到容量时，安全箱可能仍有物资。画面依据见[满仓状态](../screens/贝果计划.md#满仓状态)。

点击「返回研究站」可回到达塔前的大世界。再次与达塔交互才能打开贝果主界面。从研究站直接打开的仓库没有「返回研究站」按钮。

批量出售按以下顺序操作：

1. 点击「批量出售」。底栏显示「取消出售」「批量选择」和「确认出售」。
2. 点击「批量选择」，打开「快速选择」。
3. 按类型和稀有度筛选，核对符合条件的数量。
4. 确认筛选结果，返回出售底栏。
5. 点击「确认出售」，打开出售预览。
6. 确认出售预览，完成出售。

批量出售可能涉及安全箱中符合筛选的物品，不能假定只出售仓库库存。完整出售范围尚缺少归档的连续实机证据；现有[满仓截图](../screens/贝果计划.md#来源说明)只能证明安全箱有残留。

出售后，游戏弹出「获得」齿轮硬币的提示。物品格上的黄点表示「建议出售」，不表示稀有度。

## 尚未核实

以下游戏规则尚不明确：

- 玩法解锁条件和刷新周期。
- 箱子掉落率。
- 解锁失败后的完整重试规则。
- 满仓时批量出售是否影响安全箱物品，以及具体筛选范围。
