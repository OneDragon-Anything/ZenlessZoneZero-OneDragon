# 快捷手册

绝区零**玩法总入口**(绝大多数周期 / 常驻玩法的统一入口)。大世界右上角「快捷手册」按钮进。5 个 TAB(目标 / 日常 / 训练 / 作战 / 战术),每 TAB 列玩法卡片(玩法名 + 奖励进度 + 「前往」传送按钮)。

**为什么重要**:式舆防卫战 / 迷失之地 / 零号空洞 / 危局强袭战 / 咖啡店 / 影像店 / ... 等玩法入口都在这里;app `TransportByCompendium(tab, category, mission_type)` 经此传送。

## 何时出现 + 状态流转

- **入口**:大世界 右上「快捷手册」按钮(~1531,60,需 pc_alt)→ 快捷手册。
- **流转**:选 TAB → 点玩法卡片「前往」→ 传送确认「是否立即传送?」→ 点「确认」→ 传送到该玩法入口。
- **退出**:esc / 左上返回 → 大世界。

**TAB 切换**(顶部,y~161):目标(769)/ 日常(955)/ 训练(1142)/ 作战(1330)/ 战术(1514)。

## 识别特征(稳定锚点)

- **TAB 文字**:目标 / 日常 / 训练 / 作战 / 战术(顶部,稳定;TAB-XX text area)。
- **QUICK ... HANDBOOK**(左上标题)。
- **资源栏**(右上角):三段右对齐数字 —— 电量(3 位,如 240/240)、储蓄电量(4 位上限 2400)、以太电池数(3 位上限)。`ChargePlanApp.check_battery_charge` 运行「电量检测」图像分析流水线:按「快捷手册->以太电池」区域裁剪,再做 HSV 过滤,最后整栏 OCR;取数时以 `/` 分界取左段数字,按检测框中心与三个字段的固定中心锚点比对归位,缺字段补 0。同一栏另有「以太电池」模板 area(battery 图标)。

## 识别快照

### 1. 目标 TAB(source_image: screens/快捷手册/目标TAB.webp)

- **匹配画面**:`快捷手册-目标` is_precise=true
- **TAB**:目标 / 日常 / 训练 / 作战 / 战术
- **内容**(目标 / 进度类玩法):运算中枢修复计划(阶段 319)、绳匠传奇、数域特训、高压测试、集训效率、「布连邦」/「好棒邦」奖章 等。

### 2. 作战 TAB(source_image: screens/快捷手册/作战TAB.webp)

- **匹配画面**:`快捷手册-作战` is_precise=true
- **内容**(作战玩法,各带「前往」+ 周限倒计时):
  - 零号空洞、迷失之地、**式舆防卫战**(04 天 13 时)、危局强袭战(09 天)、溯影行动、临界推演、拟真鏖战试炼、断层之谜、区域探索、结局收集。
  - 顶部:悬赏委托进度 8000/8000、剩余时间。

### 3. 训练 TAB「特训目标」

#### 3.1 材料列表顶部(source_image: screens/快捷手册/特训目标-材料.webp)

- **入口**：选择顶部「训练」TAB，再选择左侧分类「特训目标」。
- **内容区域**：`[490, 440, 1650, 930]`，对应 screen_info 的「特训目标-内容列表」。
- **顶部状态**：实拍包含「技能」分组；第一项显示材料进度、`20-100` 电量和「前往」，第二项显示材料进度、`40-80` 电量、「燃竭」标记和「前往」。
- **传送落点**：实拍依次验证，`20-100` 进入实战模拟室方案，`40-80` 进入专业挑战室且燃竭模式开启。

#### 3.2 驱动盘列表(source_image: screens/快捷手册/特训目标-驱动盘.webp)

- 向下滚动后出现「驱动盘」分组，各项显示固定 `60` 电量和「前往」。
- 实拍第一项「迅脊与裂爪」的「前往」可直接进入同名区域巡防关卡。
- 推荐名称和顺序属于动态内容，不能作为固定识别锚点。

#### 3.3 列表位置

- 离开「特训目标」分类后再切回，可稳定回到列表顶部。
- 单纯向上拖动不一定能回到顶部，因此需要读取第一项时应先切换一次分类。
- 「前往」按钮会打开通用传送确认框；确认后直接到所选项目对应的副本入口。
