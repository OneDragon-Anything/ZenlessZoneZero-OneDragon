# 贝果计划画面

研究站入口、入场、局内和仓库。玩法见 [贝果计划](../gameplay/贝果计划.md)，自动化见 [贝果计划自动化](../../develop/zzz/application/bagel.md)。区域坐标以 `assets/game_data/screen_info/bagel_*.yml` 为准。截图在测试仓 `screens/贝果-*`。

`bagel_hub.yml` 含达塔前、对话和主界面。主界面标题才是该画面的识别标记。只看到名字，不代表已经在交互范围内。`bagel_map.yml` 是选图页，不是局内大地图。

通用确认框可能和别的玩法撞车。入场必须读完整贝果提示。投资页也带研究站标题，不能只凭标题当成已经回到主界面。

## 各画面要点

**达塔前与对话。** 名字可能在画面中部偏左，也可能居中。对话里只点明确的「出发出发」。

**选图。** 未选中的难度文字也会出现，不能只凭「困难」或「高危」四个字判断已选中。高危页签高亮时，推荐等级 Lv.60，推荐装备价值 258000。

**备战。** 备战页不显示当前地图名称，左上返回按钮回到选图。城郊高危与雅努斯高危的推荐价值同为 258000，不能凭价值确认地图；参考截图为 `screens/贝果-选图/城郊高危-20260926.webp` 和 `screens/贝果-备战/城郊高危零携带-20260926.webp`。零携带时三个价值都是 0。价值要读完整行，不能裁掉高位数字再读末位。金币图标可能被当成「0」。

**入场确认。** 困难零携带的三句是：装备价值为 0、未达推荐价值 72100；存在未装备武备的代理人；未穿戴队伍装备（异体刃、抗蚀器）。高危的价值句里是 258000，后两句相同。投资金额是白色，金币图标是金色；读金额时滤掉金色，也不要裁掉数值左边。

**局内与开局地图。** 加载画面只有雅努斯名称，不能当可以移动。开局大地图用「图例」和红底返回（复用 `menu/back`）识别，点返回后等 UPROAR。大地图上的地名不能当成已经定位到玩家。角色箭头尖端和右侧黄色视野扇区不是同一个方向，不能把静止箭头直接当成镜头方向。

**交互提示。** 可交互物在屏幕右侧弹出提示条，大约一条 75 像素高，最多同时 3 条；多于 3 条时顶部有「切换」。`交互提示` 盖住切换行和 3 个位置。`武备箱交互`、`电子保险箱交互` 用同一区域加文字。当前按 F 只对选中的那条生效。箱子头顶的名字不是这条提示；受攻击时可以只剩头顶名字，不能据此当成能按 F。圆形 F 键用图标模板，字母识别会漏，或把 F 读成 D。

**电子保险箱解锁。** 上部中心「精确点按 F 或 Space」，其下进度 0/4 到 4/4。底部「解锁过程中受到攻击会被打断」。成功后容器标题变为「电子保险箱」，状态从「搜查中…」到「搜索结果」；前者表示搜索仍在继续，不等于可以关闭面板。

**电子保险箱交互前的 OCR 样本。** `source_image: screens/贝果-局内/电子保险箱交互-HUD错字-20260930.webp`。原生1080p实拍中，右侧 F 与电子保险箱提示清晰可见，左侧 `UPROAR` 被 OCR 识别成 `IPROAR`。截图以无损 WebP 保存并遮挡 UID，保留小字识别的原始像素；自动化容错规则见[贝果应用说明](../../develop/zzz/application/bagel.md)。

**暂停、退出、结算。** 暂停菜单沿用战斗菜单的退出区域。空局结算的撤离点是「无」；不能据此推断安全箱丢了，也不能据此证明物资留下了。结算要读完整地图标题，困难和高危不是同一句。

**仓库。** 「全部(N/M)」的 N 是占用。安全箱空不空看格子，不能把没读到物品名当成空箱。研究站直接打开的仓库没有「返回研究站」；结算仓库才有，批量出售时这个按钮会被「确认出售」换掉。快速选择未选中是深灰底，选中是蓝底，大约 RGB (0,145,255)，再点一次会取消。按钮上少量蓝像素（例如门禁卡图标）仍算未选中。出售预览的确认和底栏「确认出售」、获得硬币的确认，是三块不同区域。战术棱镜的文字有时被读成「战术楼镜」，这块匹配放宽到 0.75。

2026-09-24 仓库占用从 276/280 入仓到 280/280 后，点击「返回研究站」弹出撤离奖励提示。弹窗标题与完整说明都在，确认后落在达塔前；不能把这个确认与出售确认混用。

## 格子

仓库格子和局内搜查格用同一套角标，不要用快速选择按钮上的图标当模板。类型名：战术棱镜、装备、战术道具、贵重物品、门禁卡、其他。战术棱镜至少有铃铛和人像两枚。材料是白色箱子，对照图在 `assets/game_data/bagel/item_badges/material.png`。金币是白圈，对照图是同目录 `currency.png`。对不上的角标先当「其他」。搜索窗要比格子再向左上扩 8 像素，避免切掉圆形角标上沿。

2026-09-30 用户提供的背包局部实拍已归档为 `screens/贝果-局内/背包BC品质局部-20260930.webp`。原图为 518×289，未缩放，以无损 WebP 保留颜色；这是局部样本，不能用整屏 1080p 坐标裁剪。样本两排五格，局部格心为横坐标 `(60,161,262,362,463)`、纵坐标 `(100,228)`。第一排品质为 C、B、B、B、C；第二排为 A、B、空、空、空。格子两侧底色的 OpenCV HSV 色相中位数约为 C 73、B 109、A 139，蓝底不能混入紫底 A 色带。该图覆盖品质识别，不作为局内搜查详情或整屏状态识别的依据。

搜查结果是两排五格。背包在搜查面板里先看到两排五格，更多格要点箭头，当前识别只用看得见的十格。右侧格子只有图标和数量或等级，没有完整名称。画面上有「F 全部拾取」和「双击搬运」，不表示这两下会进安全箱。

仓库里单击格子会弹出详情，不搬运。浮窗按钮的高度随物品变，不能把一种物品的按钮位置用到所有详情上。详情里的词条等级不是物品等级。局内搜查的详情布局还没实拍，不要套仓库坐标。

## 缺口

- 代理人武备价值非零的原生备战图。
- 仓库满的单独画面。
- 局内物品详情。
- 货币拾取后，主动退出是否还留着这笔钱。
