# 贝果计划画面合集

研究站入口、入场、局内和仓库。玩法见 [贝果计划](../gameplay/贝果计划.md)，自动化见 [贝果计划自动化](../../develop/zzz/application/bagel.md)。区域坐标以 `assets/game_data/screen_info/bagel_*.yml` 为准。

| 结算 | DEFEAT、地图名、继续 | 继续 → 仓库 |

| 搜查面板 | 右侧容器标题、搜查中或搜索结果；左下安全箱 | 搜查中可拖已显露物品，搜索结果出现后才关面板、按 Esc 退出 |

`bagel_hub.yml` 含达塔前、对话和主界面。主界面标题才是该画面的识别标记。只看到名字，不代表已经在交互范围内。`bagel_map.yml` 是选图页，不是局内大地图。

通用确认框可能和别的玩法撞车。入场必须读完整贝果提示。投资页也带研究站标题，不能只凭标题当成已经回到主界面。

## 各画面要点

**达塔前与对话。** 名字可能在画面中部偏左，也可能居中。对话里只点明确的「出发出发」。

**选图。** 未选中的难度文字也会出现，不能只凭「困难」或「高危」四个字判断已选中；需要核对页签高亮与当前地图。推荐等级和装备价值以当前界面显示为准。

**备战。** 备战页不显示当前地图名称，左上返回按钮回到选图。不同地图在同一难度下可能显示相同推荐价值，不能凭价值确认地图。零携带时三个价值都是 0。价值要读完整行，不能裁掉高位数字再读末位；金币图标可能被当成「0」。

**入场确认。** 零携带提示包括装备价值为 0 且未达推荐价值、存在未装备武备的代理人、未穿戴队伍装备（异体刃、抗蚀器）。推荐价值随难度变化，需要读取完整提示。投资金额是白色，金币图标是金色；读金额时滤掉金色，也不要裁掉数值左边。

**局内与开局地图。** 加载画面只有雅努斯名称，不能当可以移动。开局大地图用「图例」和红底返回（复用 `menu/back`）识别，点返回后等右下普通攻击按钮。大地图上的地名不能当成已经定位到玩家。角色箭头尖端和右侧黄色视野扇区不是同一个方向，不能把静止箭头直接当成镜头方向。

**交互提示。** 可交互物在屏幕右侧弹出提示条，大约一条 75 像素高，最多同时 3 条；多于 3 条时顶部有「切换」。`交互提示` 盖住切换行和 3 个位置。`武备箱交互`、`电子保险箱交互` 用同一区域加文字。当前按 F 只对选中的那条生效。箱子头顶的名字不是这条提示；受攻击时可以只剩头顶名字，不能据此当成能按 F。圆形 F 键用图标模板，字母识别会漏，或把 F 读成 D。

**电子保险箱解锁。** 上部中心「精确点按 F 或 Space」，其下进度 0/4 到 4/4。底部「解锁过程中受到攻击会被打断」。成功后容器标题变为「电子保险箱」，状态从「搜查中…」到「搜索结果」；前者表示搜索仍在继续，不等于可以关闭面板。

**搜查受击中断。** 搜查或拖拽期间受到攻击，可能导致搜查面板消失并回到局内；右侧交互提示不一定同时出现。不能把单帧标题漏识别直接当作受击。自动退出重开的条件见[贝果应用说明](../../develop/zzz/application/bagel.md)。

**电子保险箱交互。** 右侧 F 图标、电子保险箱提示和右下普通攻击按钮共同构成交互判断条件。具体规则见[贝果应用说明](../../develop/zzz/application/bagel.md)。

**暂停、退出、结算。** 暂停菜单沿用战斗菜单的退出区域。空局结算的撤离点是「无」；不能据此推断安全箱丢了，也不能据此证明物资留下了。结算要读完整地图标题，困难和高危不是同一句。

**仓库。** 「全部(N/M)」的 N 是占用。安全箱空不空看格子，不能把没读到物品名当成空箱。研究站直接打开的仓库没有「返回研究站」；结算仓库才有，批量出售时这个按钮会被「确认出售」换掉。快速选择未选中是深灰底，选中是蓝底，大约 RGB (0,145,255)，再点一次会取消。按钮上少量蓝像素（例如门禁卡图标）仍算未选中。出售预览的确认和底栏「确认出售」、获得硬币的确认，是三块不同区域。战术棱镜的文字有时被读成「战术楼镜」，这块匹配放宽到 0.75。

返回研究站时若出现撤离奖励提示，需要同时核对弹窗标题与奖励转移说明；不能把这个确认与出售确认混用。

### 满仓状态

仓库占用达到容量时，安全箱仍可能有遗留物品。仓库主界面可同时显示「放入仓库」「批量出售」和「返回研究站」，不能依赖独立弹窗判断仓满。

识别时分别读取「仓库数量」区域和「安全箱格子」区域；仓库占用达到容量与安全箱仍有物资是两个条件，不能相互替代。容量与遗留物资不能说明腾位方式或批量出售范围。自动化停止规则见[应用说明](../../develop/zzz/application/bagel.md)。

## 格子

仓库格子和局内搜查格用同一套角标，不要用快速选择按钮上的图标当模板。类型名：战术棱镜、装备、战术道具、贵重物品、门禁卡、其他。战术棱镜至少有铃铛和人像两枚。材料是白色箱子，对照图在 `assets/game_data/bagel/item_badges/material.png`。金币是白圈，对照图是同目录 `currency.png`。对不上的角标先当「其他」。搜索窗要比格子再向左上扩 8 像素，避免切掉圆形角标上沿。

角标模板位于 `assets/game_data/bagel/item_badges/`。白色图案应完整保留并居中；贵重物品的钻石图案为 24×26 像素，其余模板为 24×24 像素。

| 模板 | 类型 |
|---|---|
| `prism_char.png`、`prism_bell.png` | 战术棱镜 |
| `equip.png` | 装备 |
| `valuable.png` | 贵重物品 |
| `keycard.png` | 门禁卡 |
| `currency.png` | 金币 |
| `tactic.png` | 战术道具 |
| `material.png`、`other.png` | 材料 |

`other.png` 与 `material.png` 都是白色箱子材料角标，识别时统一归为材料，使用相同的入箱优先级；未匹配的角标按「其他」处理。

底色表示稀有度：红是 Z，金是 S，紫是 A，蓝是 B，绿是 C。要看格子左右两侧，不要用整格中位数；红底上的金色图案会把 Z 判成 S。对不上的底色仍为未知。格上黄点是「建议出售」。

局部截图不能套用整屏 1080p 坐标。品质识别应区分蓝底与紫底，不把 B 判成 A；局部格子颜色不能作为整屏状态识别依据。

搜查结果是两排五格。背包在搜查面板里先看到两排五格，更多格要点箭头，当前识别只用看得见的十格。右侧格子只有图标和数量或等级，没有完整名称。画面上有「F 全部拾取」和「双击搬运」，不表示这两下会进安全箱。

仓库里单击格子会弹出详情，不搬运。浮窗按钮的高度随物品变，不能把一种物品的按钮位置用到所有详情上。详情里的词条等级不是物品等级。局内搜查的详情布局尚未明确，不要套仓库坐标。

## 缺口

- 代理人武备价值非零的原生备战图。
- 局内物品详情。
- 货币拾取后，主动退出是否还留着这笔钱。
