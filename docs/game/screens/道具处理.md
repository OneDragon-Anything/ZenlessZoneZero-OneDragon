# 道具处理

仓库的「道具处理」子界面,对可合成/分解/摧毁的道具做批处理。**合成电池**玩法(`ExchangeEtherBattery`)经此合成以太电池。三个页签:**合成 / 分解 / 摧毁**(顶部右侧横排)。本画面是模态多子态:主界面(合成页)+ 合成确认弹窗 + 获得弹窗。

**为什么重要**:`ChargePlanApp` 的「合成电池」计划分流到此,把 60 电量(+ 储值电卡 + 丁尼)合成为 1 个以太电池囤积;`ExchangeEtherBattery` 在此完成「检查素材 → 合成 → 确认 → 领取」全流程。

## 何时出现 + 状态流转

- **入口**:
  - 快捷手册资源栏点「以太电池」图标 → 弹资源详情 → 点「[获取]合成」→ 道具处理(合成页)。`ExchangeEtherBattery` 走此路(`click_ether_battery` → `click_synthesize_entry`)。
  - 仓库-材料道具页点「道具处理」按钮 → 道具处理(见 [仓库-材料道具](仓库-材料道具.md))。
- **页内流转**(合成页为基准态):

| 当前态 | 动作 | 下一态 |
|---|---|---|
| 合成页 | 点「合成」按钮 | 合成确认弹窗 |
| 合成确认 | 点「确认」 | 获得弹窗 |
| 合成确认 | 点「取消」 | 合成页 |
| 获得弹窗 | 点「确认」 | 合成页(合成完成,数量 +1) |
| 合成页 | 点左上「返回」 | 入口来源(快捷手册详情 / 仓库-材料道具) |

**合成数量**:右侧有 `-` / 滑块 / `+` 数量调节,默认 ×1。`ExchangeEtherBattery` **不调数量**,固定 ×1 合成、靠计划次数(`plan_times`)循环多次。

## 备注

- **画面识别限定列表**:`ExchangeEtherBattery.wait_item_process` 用 `check_and_update_current_screen(['道具处理'])` 传限定列表,能正确命中;MCP `analyze_screen` 不传列表走 BFS,会误匹配「委托助手 / 菜单」等(`is_precise=false`),**不是 bug**——op 内限定判断与 MCP 全局匹配路径不同。
- **合成页/确认/获得 三个 screen_id**:`item_processing` / `item_processing_confirm` / `item_processing_obtained`,各自独立 yml + 合并缓存。
- **合成消耗实证**(2026-07-22 live):1 个以太电池 = 60 电量 + 100 储值电卡 + 丁尼;`estimated_charge_power` 只预估 60 电量,储值电卡/丁尼消耗未预估(玩家通常囤积,属合理省略)。
- **易变值**:道具拥有量、资源数值、丁尼余额勿当特征。
