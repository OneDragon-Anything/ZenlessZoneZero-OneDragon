## 迷失之地-通用选择

`handle_interact` 识别到此画面后委托 `LostVoidChooseCommon`。是「选 N 个」类选择的**容器画面**,涵盖选鸣徽(藏品)、选卡牌、选武备、选战术棱镜方案强化方向等多种子态,由**顶部标题** OCR 区分(见下表)。

**状态流转**:
- 入口 = 层间移动中交互(感叹号 NPC / 白点 / 下层入口)后,`handle_interact` 精准匹配本画面 → 委托 `LostVoidChooseCommon`。
- 出口 = 选满 N 个 → 点「按钮-确定」→ 返回大世界 → `after_interact`。

**子态(按 `区域-标题` OCR,代码 `check_choose_title`)**:

| 标题文案 | 规则 | 含义 | 需选数 |
|---|---|---|---:|
| 请选择1张卡牌 | CHOOSE_1_CARD | 选 1 张鸣徽/卡牌 | 1 |
| 请选择1个武备 | CHOOSE_1_GEAR | 选 1 个武备 | 1 |
| 请选择2项 / 请选择2枚鸣徽 / 两枚鸣徽 | CHOOSE_2 | 选 2 个 | 2 |
| 请选择1项 / 请选择1枚鸣徽 | CHOOSE_1 | 单选(1.5 后武备/鸣徽都可能) | 1 |
| 获得武备 / 武备已升级 | GEAR_GAIN / GEAR_UPGRADE | 武备获取/升级(无需选,直接确定) | 0 |
| 获得战利品 | ARTIFACT_GAIN | 藏品获取(无需选) | 0 |
| 请选择战术棱镜方案强化的方向 | GEAR_BRANCH | 武备分支二选一 | 1 |

> 标题未命中时,用 `区域-武备标识`(template `common_choose_gear`)兜底判断武备单选。

**识别特征(稳定锚点)**:
- `按钮-确定` — `id_mark=true`,`text=确定`,`pc_rect=[855,795,1165,975]`,`lcs_percent=0.7`(2026-07-26 已收紧,见备注)。
- `迷失之地-TAB` — `id_mark=true`,template `normal_world_tab`,`pc_rect=[0,482,102,600]`(左下角小地图/TAB 图标)。

**可交互元素**:
- 卡牌 / 藏品(中央,横向排列):点击选取;选中态靠 `区域-藏品已选择` OCR「已选择」「有同流派武备」判断。
- `按钮-确定`(下方居中):确认;**多选时按钮文字带 `(x/y)` 计数**(代码 `_get_chosen_count_from_confirm_button` 解析 `(\d+)/(\d+)`)。
- `按钮-刷新`(右上 `[1672,22,1830,76]`,`color_range` 白色)。
- `文本-详情`(左上 `[74,24,142,80]`)。
- 其他区域:`区域-标题` / `区域-藏品名称` / `区域-武备名称` / `区域-藏品已选择` / `中间区域-识别黑屏`(黑屏点击兜底用)。
