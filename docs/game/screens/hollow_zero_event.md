# 零号空洞-事件

本文只记录门扉入口子态，其余事件尚待补档。玩法见[枯萎之都](../gameplay/withered_domain.md)。

## 何时出现与状态流转

地图中接近门扉时，右侧显示入口选项。代表图为当前层数 3/3，电视格地图仍然可见。
点击入口后是否通行需要看后续画面；单张截图和按钮文字不能证明条件已经满足。
条件满足后的开启态、条件不满足时点击的反馈、侵蚀门事件对话均待实拍。

## 识别特征与可交互元素

- 右下方入口文字为“开门”，旁边有蓝色圆形图标和数字快捷键 1。
- 说明文字为“上一场「守门人」战斗获得S评价可通过”，是条件说明，不是评价结果。
- 底部有“背包”，左上角有“当前层数”；层数是动态值。
- 入口可点，地图格也可点；两者可能互相遮挡，不能以入口文字判断格子已通行。
