# 咖啡店（每日咖啡）

`coffee` app 每日进入咖啡店点单。脚本会先尝试不占用每日次数的额外咖啡，再固定选择汀曼特调作为正式咖啡；喝完后返回大世界。

## 入口 + 状态流转

大世界 → `Transport` → `interact(F)` → 咖啡店 → 选咖啡 → 点单 → 电量确认 → 返回大世界。

Transport 3 点(`CoffeeTransportPoint`):
- **POINT_1 六分街-咖啡店**:传送后 `turn_to_angle(180)` 转正西 + `move_w` + interact → 咖啡店画面(直接选咖啡)。
- **POINT_2 澄辉坪-汀曼咖啡** ⭐:传送落点正对入口,直接 interact → **对话点单**(汀曼大师对话框选咖啡)。
- **POINT_3 布亚斯特城区-片刻闲** ⭐:传送落点正对入口,直接 interact → **对话点单**;二次运行有两个连续的纯对话框,需逐个点击。

流转(`CoffeeApp` `@operation_node` 链):
传送 → 等待大世界/咖啡店加载 → 移动交互 → (POINT_2/POINT_3 对话点单:`对话框标题-汀曼大师` → 按“额外咖啡优先、汀曼特调兜底”的顺序尝试点击;没有命中则 OCR 点击对话框标题推进对话,直到成功点单或回到大世界;不根据区域文字判断状态) → 选择咖啡 → 点单 → (不占用确认 / 点单后跳过)→ 电量确认 → 返回大世界。

额外咖啡完成电量确认后会回到“选择咖啡”，继续尝试尚未喝过的额外咖啡，最后点汀曼特调。返回大世界后，再按原配置决定是否运行普通体力计划。

### 2. 对话点单-选项态(POINT_3 片刻闲,未喝过)(source_image: screens/咖啡店/对话点单-选项.webp)

- 出现:POINT_2/POINT_3 交互后(当天未喝)→ 汀曼大师对话框 + `右侧选项区域` 咖啡列表。POINT_3 二次运行(已喝过)则前置两段纯对话框,需逐个点标题推进(见 §1 已喝过态)。
- 匹配画面:`咖啡店`(is_precise=false)。
- 匹配 area:

  | area | 类型 | 文本 | 位置 |
  |---|---|---|---|
  | 对话框标题-汀曼大师 | text | 汀曼大师 | 880,800-1040,840 |

- 全量 OCR:汀曼大师 / 您好,想要喝点什么?…这样的下雨天和热咖啡很配呢(对话正文)/ `右侧选项区域` 咖啡列表 / 招牌(MADE BY TINMASTER / TEA FIRST / 片刻闲 CuppaMoment)。
- 关键 area:`右侧选项区域`(`1438,536-1914,830`)—— app `dialog_choose_coffee` 在此按优先级 OCR 点击额外咖啡或汀曼特调(未命中则点 `对话框标题-汀曼大师` 推进)。
- **实拍验证(POINT_3)**:transport 到片刻闲 + 直接 `interact F`(**无需 move** —— 落点在交互范围,F 自动锁定汀曼大师;昨日误判需导航)→ 选项态;`对话框标题-汀曼大师` area(约 909,800)位置正确命中。
- 流转:app OCR 点候选咖啡 → `已点单` → 点单后跳过 → 电量确认 → 返回大世界。
