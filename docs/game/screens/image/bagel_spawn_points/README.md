# 贝果出生点素材

本目录保存雅努斯幻境的出生位置代表帧及小地图定位对照。以下五处均有实际入场画面依据；已有素材不足以证明出生点清单完整。

“工地深处”为项目使用的显示名，其余名称沿用项目现有路线。游戏内正式点名未全部确认。`Custom` 是项目底图分层名，不是游戏内显示的楼层名称。

## 坐标方法与限制

- 源视频解码图像为 1920×1080。小地图取矩形 `[1533,206,1734,407)`，圆形有效区半径为 88 像素。
- 在雅努斯各分层底图上进行纹理匹配，层内圆心加分层 `origin` 得到全局坐标。五处最佳匹配层均为 `Custom`，其 `origin` 为 `(0,0)`。
- 原始解码帧的前三名匹配结果见 [positions.json](positions.json)。分数为图像相关系数，不是置信概率。工地深处的最佳相关系数约为 0.3723。
- 整数坐标不表示误差为零。底图采集误差、录像压缩误差和地图像素对应的实际距离未完成标定。
- 路线首点与出生点不是同一对象。例如改建工程区旧路线首点为 `(606,52)`，与录像定位中心相差约 22.4 地图像素。
- 归档画面用于复核位置与外观，不代替出生识别阈值或导航流程的实机验收。不能将同一难度的素材直接外推到其他难度或版本。

## 来源与处理

来源标识、帧时间、原解码帧校验值以及定位底图校验值见 [sources.json](sources.json)。V01 对应连续运行的 run02 原录像，V02 对应 run03 原录像，V13 对应单次 run03 原录像；源文件识别名称记录在该索引中。原录像未纳入本目录，以上归档图片和定位对照可独立查看，不依赖私人路径或临时目录。

整屏帧未缩放，右下矩形 `[1780,1050,1920,1080)` 涂黑遮挡账号标识，再使用项目画面建档工具转为质量 90 的 WebP。定位对照 PNG 和总览保留分析产物原像素。源视频本身经过有损编码，PNG 不能恢复原始游戏采集精度；`positions.json` 的分数来自 WebP 转换前的解码帧，不应要求重新压缩后的图片产生完全相同的分数。

归档文件校验值见 [sha256.json](sha256.json)。出生点登记与路线开启规则见[贝果路线与出生点](../../../../develop/zzz/application/bagel_route_storage.md)，分层坐标规则见[固定地图说明](../../../../develop/zzz/application/bagel_fixed_map.md)。
