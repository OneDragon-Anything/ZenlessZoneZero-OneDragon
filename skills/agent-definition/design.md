# 设计记录

## HSV 采集脚本

代理人状态的 HSV 范围不能只根据单张截图估计。资源显示会受抗锯齿、特效、亮度变化和空状态灰色影响，需在实际游戏画面中持续采样后再设定范围。

脚本放在 `agent-definition` skill 内，因为它服务于角色状态模板和 `AgentStateDef` 的颜色参数；不放入项目源码，避免将一次性的采集入口混入运行时功能。

脚本从状态模板读取区域与 `mask.png`，而非内置坐标。这样模板坐标修改后采集范围自动同步，也能复用于不同代理人、队伍人数和位置。

采集过程只在内存中保存各状态的 HSV 通道值，并在结束后合并连续区间后输出。颜色调参需要的是连续主区间，不需要高频写入逐像素数据；同时避免产生大量调试文件。

蕾米埃尔最终采用 `hsv_color=(150, 255, 255)`、`hsv_color_diff=(30, 255, 200)`，即 H 120–179、S 0–255、V 55–255。这个结果表明资源的色相足以作为主要区分条件，S/V 应保留足够余量覆盖显示变化；但 V 下限仍用于排除暗色背景。该数值只记录为本次设计依据，不应被当作其他角色的默认参数。

截图通过 `ZContext` 初始化的控制器获取，沿用当前实例配置中的截图方式和窗口标题；脚本不发送鼠标、键盘或手柄输入，避免干扰游戏状态。
