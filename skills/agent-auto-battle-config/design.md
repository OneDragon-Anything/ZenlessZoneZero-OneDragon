# 设计记录

## 定位

这个 skill 约束自动战斗 YAML 的操作、状态处理器和模板引用写法。它不定义具体角色的战斗逻辑。

## 合并流程

自动战斗运行时读取 `.merged.yml`，但人工维护源是 `sample.yml`。因此在 skill 中明确禁止直接修改 `.merged.yml`，并要求改完 sample 后调用 `new-config` 的构建脚本。

这样可以避免源文件与运行产物分叉，也让所有自动战斗目录的合并结果保持一致。构建产物需要提交，因为运行时依赖它。

## CG 与失衡计时

游戏内 CG 或播片会暂停失衡计时，但 `自定义-失衡时间` 仍按真实时间变化。技能模板若包含这类演出，必须以实测 CG 时长使用 `seconds_add` 补偿，否则后续判断会提前认为失衡结束。该规则写在 `SKILL.md` 的倒计时方法旁，避免只知道负值可延长状态，却遗漏它的必要使用场景。

## 长按与并发输入

长按不能只发送一次按下再等待。自动战斗的其他并发操作可能对同一按键发出松开事件，使长按提前结束。因此 `SKILL.md` 规定长按期间每 0.5 秒重复发送按下，并在结束时显式松开。
