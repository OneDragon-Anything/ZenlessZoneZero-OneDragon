# ZODE 增强分支

ZODE（Z One Dragon Enhanced）是本仓库维护的增强发行分支：**官方 main + 社区精选 PR + 维护者增强**。代码更新机制与官方版完全一致，在一条龙「资源管理」中选择 idk500 增强源（GitHub / CNB）+ ZODE 分支即可使用。

## 目标：社区自治，不是中心化审查

ZODE 的存在意义，是让社区的好改动不被"排队等少数人 review"阻塞：

- **规则全部成文**：合入流水线、冲突处理、仲裁流程见 [docs/develop/zode/maintenance.md](docs/develop/zode/maintenance.md)，每个周期合了什么、为什么、有什么分歧，清单与提交历史全程公开可查；
- **分歧靠公开仲裁**：有争议的改动开仲裁帖，摆出各方方案对比，社区投票决定，不靠维护者关门拍板；
- **参与不需要审批**：任何人都可以提 PR、开 issue、评论、投票。

## 参与即信用

你的每一次参与，都会形成公开的信用累积：

- **提交 PR**：以原始提交保 SHA 合入，作者姓名与日期原样保留，合并说明与首页公告都会署你的名；
- **开 issue / 评论 / 投票**：讨论记录长期公开，是社区形成判断的依据。

信用不是评分，是公开的行动记录——社区据此决定信任谁。

## 对自己的行动负责

信用与责任对等，这是社区自治的前提：

- 提 PR 前先读 PR 描述与评论区，说明你的改动与现有实现的关系；
- 你的 PR 有问题时，我们会把建议更改评论在你的 PR 下，等你确认后合入，不会替你悄悄改掉；
- 发现自己的改动有问题，主动跟进修复——这会增加你的信用，而不是损耗它。
